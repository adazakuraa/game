# APEX LINE — 3D レーシング（GT・ラリー・ロードバイク）

ブラウザで動く 3D レースゲーム（Three.js）。4 つのジャンルを遊べます。スマホのタッチ操作を主な対象にしています。PC のキーボードやゲームパッドでも遊べます。

`racing/index.html` を静的サーバーで開くだけで動きます。ビルドも外部 CDN も不要です（Three.js は `vendor/` に同梱）。

```
python3 -m http.server 8000   # リポジトリ直下で実行し、http://localhost:8000/racing/ を開く
```

## ジャンル

| ジャンル | イメージした大会 | 内容 |
|---|---|---|
| GT レース | GT 選手権 | 5 サーキット。CPU 7 台と周回レース、ゴースト付きタイムアタック |
| ラリー | 世界ラリー選手権（雪のモナコ、北欧の高速グラベル、サバンナ） | 一本道のステージをタイムで競う。舗装・砂利・土・雪・凍結・砂で路面が変わり、ペースノート（矢印と 1〜6 の数字）でコーナーを予告 |
| ロードバイク | グラン・ツール（大通りの最終ステージ、山頂ゴール、石畳のクラシック） | 8 人の集団レース。「全力」でスタミナ（W'）を使い、前の選手の真後ろ（スリップストリーム）で脚を貯めてゴールスプリント |

## 遊び方

- **レース**: CPU 7台と 2/3/5 周で勝負。プレイヤーは**最後尾スタート**。画面中央の 3・2・1・GO! のカウントダウンで発進（ラリー・ロードバイクも同じ）。
- **タイムアタック**: 1台で走り込み。自己ベストの走りは**ゴースト**（半透明の車）として再生され、通過時点ごとの差（±秒）が表示されます。スタートはレースと同じグリッド位置・カウントダウンから。記録は**1・2周目の合計タイム**で、2周走ると計測終了です。ゴーストも記録の2周を再生します。レースのラップタイムは記録として残しません。
- 難易度: かんたん / ふつう / むずかしい。

### ゲーム性の工夫（「桜井政博のゲーム作るには」の原則を参考に）

- **リスクとリターン**: 前の車の 30m 以内・真後ろ（横のずれ 1.6m 以内）に付くと**スリップストリーム**で空気抵抗が最大 40% 減り、直線で伸びる（画面下に SLIPSTREAM とゲージ）。近いほど効くが、追突の危険も増える。CPU も同じ条件で使う。
- **ほめる演出**: 追い抜くと「OVERTAKE！ P5」、まとめて抜くと「2台抜き！」、首位に立つと「トップ浮上！」と音で知らせる（順位が 0.6 秒続いたら確定）。
- **目の前の目標**: タイムアタックはコースごとに**金・銀・銅メダル**の目標タイム（1・2周目の合計）。走行中は右上に次の目標を表示し、初めて届いたメダルにはコイン（金300・銀150・銅80）。目標タイムは全力ペースの自動ドライバーの記録をもとに `js/sim/trackdata.js` の `medals` に置いている。
- **迅速なリトライ**: 壁に引っかかって 2.5 秒動けない、または 2 秒逆走すると、その場所のレコードライン上へ自動で戻す（ロスした時間がそのままペナルティ）。逆走は 0.6 秒で警告。GT とラリーで有効（`js/sim/recovery.js`）。

### 操作

| | スマホ | PC |

## 走りの演出

- 追従カメラは車との距離を一定に保ち、コーナーでは横 G で少し振られて傾く
- 高速域（約 110km/h〜）で画面の外周に流れる線と周辺減光
- 強いブレーキでブレーキディスクが赤熱。シフトアップやアクセルオフでマフラーから炎とアフターファイヤ音
- 縁石・芝・接触でスマホが振動（Android など対応端末のみ）

## コインとガレージ（見た目カスタマイズ）

- レースの着順やタイムアタックの周回でコインがもらえます。使い道は見た目のカスタマイズだけで、車の性能は一切変わりません。
- 報酬の目安（3周・ふつうで1位なら賞金600）: 賞金は着順・難易度・周回数で変わり、ファステストラップ、クリーンレース（強い接触2回以内）、コースごとの初表彰台・初優勝でボーナスがつきます。タイムアタックは1周20コイン（1回2周）、自己ベスト更新で+80、メダル初獲得で金300・銀150・銅80です。
- ガレージでは 3D プレビューを回しながら試着でき、買う前に見た目を確認できます。
- 色のパーツ: ボディカラー（20色）、塗装（メタリック・サテン・マット・パール・クロームなど）、ストライプ（5種）とその色、ホイールの色、キャリパー色、ウインドウ（クリア・スモーク・ブラック・ミラー）、ヘッドライト色、アンダーグローとタイヤスモークの色（レインボーあり）、ゼッケン番号。
- 形のパーツ: ボディキット（ワイドフェンダー・サイドスカート）、フロント（リップ・大型スプリッター・カナード）、ボンネット（エアダクト・ルーバー・カーボン）、ルーフ（シャークフィン・ルーフスポイラー・ルーフスクープ）、車高（ローダウン・シャコタン・リフトアップ）、ホイール（5種）、リアウイング（5種）、マフラー（デュアル・センター出し・4本出し・大口径）。
- ストライプなしのままストライプ色を選ぶと、見本のストライプを付けた状態で試着表示します。
- 所持パーツと装備はブラウザに保存されます（`js/garage.js`）。

## 難易度の考え方

- 車両物理（2輪モデル + 荷重移動 + 摩擦円 + パワートレイン）を実際に操作する自動ドライバーで、各コースの「上手な人の周回タイム」を毎回測ります。
- CPU のペースはそれに対する比率で決めます（`js/sim/race.js` の `DIFFICULTY`）。
  - ふつう: トップの CPU は上手な人より約 3% 遅い。上手に走れば勝てるが、雑に走る（ペース 90〜95%）と表彰台どまり。
  - むずかしい: トップの CPU が上手な人と同じペース。
- コース外（芝・砂）はグリップと速度が大きく落ちます。縁石まではセーフです。ブレーキングポイントの目安として、コーナー手前に 150/100/50 m の看板があります。

## 構成

```
js/game/     ジャンルごとのゲーム（circuit / rally / bike）と共通部分（base）
js/genres.js ジャンルとコースの一覧
js/sim/      描画に依存しないシミュレーション（コース生成、車・艇・自転車の物理、CPU、レース進行）
js/render/   Three.js による描画（手続き的テクスチャ、車モデル、コース・背景、エフェクト）
js/ui/       入力（タッチ・キーボード・ゲームパッド）
js/audio.js  Web Audio によるエンジン音などの合成
```

画像や 3D モデルなどの外部アセットは使っていません。テクスチャも車も、すべてコードで生成しています。

参考にしたゲーム制作スキル: OpenAI `three-webgl-game`（シミュレーションと描画の分離、DOM の HUD）、majidmanzarpour/threejs-game-skills（`threejs-game-director` / `threejs-gameplay-systems` / `threejs-aaa-graphics-builder`：デザインブリーフ、難易度曲線、ライティングとマテリアルの順序、モバイルでの DPR 上限）。
