# IMPROVEMENT_TRACKER.md

レースゲームの修正依頼を、原文の内容を削らずに管理するためのトラッカー。
各項目は実装・確認後に状態を更新する。要望の統合によって意味や条件を失わないこと。

## 運用ルール

-   [ ] 以下の要望を、明示的な指示なしに削除・省略・簡略化しない。
-   [ ] 複数の要望を同じ機能で実装する場合も、個別のチェック項目は残す。
-   [ ]
    既存実装との重複がある場合は、実装済みかどうかを確認して状態を更新する。単に項目を削除しない。
-   [ ] 要望同士に矛盾や依存関係がある場合は、勝手に解釈せず記録する。
-   [ ]
    コース・パーツの追加では、既存データとの重複を確認し、同じものを二重登録しない。
-   [ ] 実装状態は `未着手` / `調査中` / `実装中` / `実装済み` /
    `確認済み` / `保留` のいずれかで管理する。
-   [ ] 「実装済み」と「動作確認済み」を区別する。
-   [ ] 本ファイルの項目数や内容を、トークン節約などを理由に減らさない。

## Phase 1：衝突・CPU挙動・道幅

### 衝突ペナルティ

-   [ ] ぶつかった時のペナルティが大きすぎるため、もっと影響を少なくする。
-   [ ]
    ぶつかった時の影響を減らすようなガレージのパーツも追加する（Phase 2にも関連項目あり）。

### CPUのカーブ挙動

-   [ ]
    CPUのカーブが相変わらず遅い問題を修正する。CPUはかなり早い段階から減速してカーブを回る感じになっている。
-   [ ]
    CPUは割と速いスピードのまま曲がっていってよい（ユーザーには難しいかもしれないが、そのままでよい）。
-   [ ]
    速度感の目安：直線を180kmで走っていた場合なら、カーブの瞬間だけドリフトで130kmくらいまで落として、そのまま曲がっていくくらいのイメージにする。
-   [ ]
    難易度「むずかしい」では、CPUが各コースに対して最適な最も強いパーツを付けるようにする。

### 道幅・ショートカット

-   [ ]
    ショートカットは道が狭すぎるのに加えて、CPUが隙間なく通っていくため、CPUが入り切るまで待たないとショートカットに行けない問題を解決する。
-   [ ]
    ショートカットに限らず、CPUの数に対して道幅が狭いという問題全般を修正する。
-   [ ]
    この問題の解決方法自体は未定であり、勝手に解釈せず「未解決事項・確認が必要な点」にも記録する。

## Phase 2：ガレージ・パーツ

### パーツの追加・バランス

-   [ ] ぶつかった時の影響を減らすようなパーツを追加する。
-   [ ] パーツの種類をもっと増やす。
-   [ ]
    明らかに強いパーツは作らず、人によってどれを選ぶかが変わりそうなバランスにする。
-   [ ] コースによって最適なパーツ構成が変わるようにする。
-   [ ]
    コースの出る順序とパーツの強さ（値段）に関連性を持たせる。安い順にパーツをしっかり揃えていくことが、次のコースの対策になるようにする。

### 性能表示

-   [ ]
    ガレージの性能について、具体的な性能値（スピード+1みたいな表示）は要らない。
-   [ ] 性能表示は既存のグラフ状のものだけあればよい。
-   [ ]
    そのグラフはデフォルトでは見せないようにしておき、タップしたら出てきたり消えたりするような切り替えで見れるようにする。

### パーツ一覧のUI

-   [ ]
    パーツをスクロールして見ていくとき、一度に画面に出る幅が小さくて見づらい問題を改善する。
-   [ ]
    選択したパーツが一番下に固定で出る仕様は要らないので、なくす。
-   [ ]
    購入ボタンや「装備中」のような表示は、各パーツと一緒に、選択時に出してほしい。

### ガレージの見た目

-   [ ] ガレージの見た目にももっとお金をかけられるようにする。最低でも500くらい。

### ガレージの解放

-   [ ]
    ガレージは最初からではなく、途中から解放されるようにする（3コース目をクリアした後など）。

## Phase 3：コース

### コースの追加

-   [ ]
    コースを増やす。今あるものも含めて合計12個になるように作る（後述のグランプリと合わせて15個）。
-   [ ] コースごとに特徴をつける。
-   [ ]
    ターボの仕様が後から追加されたため、それを駆使して走るコースがあってもよい。
-   [ ] 舞台が宇宙とか海の中みたいな、奇抜なコースがあってもよい。
-   [ ] 後半のコースほど難しい作りにする。

### コースの解放条件

-   [ ]
    コースは初めから全部開放されているのではなく、条件を満たす（前コースの順位や難易度など）ことで解放されるようにする。

### カーブの案内表示

-   [ ]
    コースのカーブは、コース内で矢印などを表示して分かりやすくしてほしい。

## Phase 4：チュートリアル・ストーリー・グランプリ・難易度

### チュートリアル

-   [ ] チュートリアルを追加する。
-   [ ]
    チュートリアルは、いきなりレースの途中から始まり、3位くらいから逆転して1位になるような感じにする。

### ストーリー

-   [ ]
    ストーリーも少し付ける。薄くてよいが、ユーザーに目的を多少持たせたい。

### グランプリ

-   [ ]
    4つのコースが解放されるごとに、グランプリみたいな新しいコースが出てくるようにする。
-   [ ]
    グランプリは順位が1位なら優勝で次に進めるようにする（何回でも挑戦可能。ただし、参加料がいる）。
-   [ ] グランプリの難易度は普通くらいでよい。
-   [ ]
    通常コース12個とグランプリを合わせて、合計15個のコースにする。
-   [ ] グランプリは後からでも挑戦できるようにする。

### 難易度選択

-   [ ]
    難易度はコースの画面で選ばせるのではなく、ゲームスタート時にeasy、normal、hardを選択させるようにする。
-   [ ] 難易度は途中からは設定で変更できるようにする。

## Phase 5：表示・操作・コンテンツ削除

### バックミラー

-   [ ] バックミラーを見れるようにする。
-   [ ]
    画面上のどこかのボタン（左上とか）を押すと、押している最中だけ後ろが見れるようにする。

### 不要コンテンツの削除

-   [ ] ラリーはいらないので消す。
-   [ ] バイクはいらないので消す。

## Phase 6：総合確認・バランス調整

### レースバランス・CPU

-   [ ] ぶつかった時のペナルティの影響が小さくなっている。
-   [ ]
    CPUがカーブ手前で早すぎる段階から減速せず、速いスピードのまま曲がっていく。
-   [ ]
    直線180km/hからカーブでドリフトして130km/h程度まで落として曲がる速度感になっている。
-   [ ]
    難易度「むずかしい」でCPUが各コース最適の最も強いパーツを装備している。
-   [ ]
    CPUがショートカットに入り切るまで待たなくても、ショートカットを使えるようになっている。
-   [ ] CPUの数に対して道幅が狭すぎない。

### ガレージ・パーツ

-   [ ] ぶつかった時の影響を減らすパーツが追加されている。
-   [ ] パーツの種類が増えている。
-   [ ]
    明らかに強いパーツがなく、プレイヤーによって選択が分かれるバランスになっている。
-   [ ] コースによって最適なパーツ構成が変わる。
-   [ ]
    具体的な性能値（スピード+1など）が表示されず、既存のグラフ表示だけになっている。
-   [ ] グラフがデフォルトで非表示で、タップで表示・非表示を切り替えられる。
-   [ ] パーツ一覧で一度に見える範囲が見づらくない。
-   [ ] 選択したパーツが画面下部に固定表示されない。
-   [ ]
    購入ボタンや「装備中」表示が、各パーツと一緒に選択時に表示される。
-   [ ] ガレージの見た目にお金をかけられる（最低でも500くらい）。
-   [ ] ガレージが途中（3コース目クリア後など）から解放される。
-   [ ]
    安い順にパーツを揃えることが次のコースの対策になるよう、コース順序とパーツの強さ（値段）に関連性がある。

### コース・進行

-   [ ] 通常コースが既存分を含めて12個ある。
-   [ ] グランプリと合わせて合計15個のコースがある。
-   [ ] コースごとに特徴がある（宇宙・海中などの奇抜な舞台、ターボを駆使するコースを含む）。
-   [ ] 後半のコースほど難しい作りになっている。
-   [ ]
    コースが最初から全開放ではなく、前コースの順位や難易度などの条件で解放される。
-   [ ] コース内のカーブに矢印などの案内表示がある。
-   [ ]
    チュートリアルがレース途中から始まり、3位くらいから逆転して1位になる流れになっている。
-   [ ] 薄いストーリーがあり、ユーザーに目的が提示される。
-   [ ]
    4コース解放ごとにグランプリコースが出現し、1位で優勝して次に進める。
-   [ ] グランプリに何回でも挑戦でき、参加料が必要で、後からでも挑戦できる。
-   [ ]
    難易度をゲームスタート時にeasy、normal、hardから選択でき、途中からは設定で変更できる。

### 表示・操作・削除

-   [ ]
    ボタン（左上など）を押している間だけバックミラーで後ろが見える。
-   [ ] ラリーが削除されている。
-   [ ] バイクが削除されている。
