## 読み方（出現率の定義）

- **対象は魚（魚類）のみ**。カニ・エビ・貝・ウニ・ナマコ・ウミウシ・イカ・タコ・クラゲ・ウミガメ・ホヤなど魚以外は対象外。
  種定義の `kind` が `fish` / `ray` / `gardenEel` のものから、哺乳類・爬虫類・鳥類（クジラ・イルカ・アシカ・アザラシ・ラッコ・ジュゴン・ウミヘビ・ペンギン。17 種）を除いた **482 種**。
- **エリア**は種定義の `zone`（図鑑の `ZONE_ORDER` 順）。`species.ts` の `MAP_MOVES` による移動（遺跡・ブルーホール・洞窟・河口）と `balanceZones()`（浅場などの個体数補正）を適用した最終値。
- **個体数 / 群れ数**は種定義の `count` / `groups`。**レア度**は `rarity`（1 普通〜3 稀、4 伝説）。
- **群れの出現確率**（`creatures.ts` の `presence`）はレア度で決まる: ★1=0.9、★2=0.6、★3=0.3、★4=0.07（群れ単位で潜るたびに抽選）。
- **期待個体数** = 個体数 × 群れの出現確率（群れに個体が均等配分されるため）。**出現率（昼）** = その魚の期待個体数 ÷ エリア内の全魚の期待個体数の合計。
- **出現率（夜）**はナイトダイブ時。昼の魚は ×0.4（`NIGHT.dayPresence`）、夜専用（`when:'night'`）は夜のみ出現、光に反応する攻撃的な個体（`aggro:'light'`）は夜は確率 1。
- 天候補正（日替わり 0.75〜1.35 倍）は 1 として扱う。★1 の種は全群れが不在でも 1 群れは必ず出る補正があるが、ここでは無視した。
- 群れの置き場所（生息点 `region`）は文字列（`reefSpots` など）か矩形 `[x0,x1,z0,z1]`。実際の出現位置は `flora.ts` の Homes から選ばれるので、割合は出さず元の値のまま載せた。深度は種定義の `depth`（m）。
