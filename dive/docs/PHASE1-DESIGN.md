## 1. 導入：ゲーム開始直後に浅瀬ラグーンの海中から始める

**対象**: 新規セーブ（`dives === 0 && !tutorial`）のみ。既存セーブは従来どおりボート画面から。

- `Game.start()`：新規セーブなら、ボート画面を出さずに `startDive(浅瀬ラグーン, …)` を呼ぶ。
  ローディング画面の直後に海中の画面になる。
- 潜水開始直後はポーズ状態にして、**プロローグのカード**（新規 `#prologue`、画面下寄りのパネル）を重ねる。
  中身は `CHAPTERS[0].intro`（下の §5 の冒頭ストーリー）と「潜りはじめる」ボタン。
  ボタンのタップが最初のユーザー操作になるので、ここで音声を解禁（`audio.unlock()`）してからポーズを解除し、チュートリアル1を出す。
- プロローグを閉じたら `storyRead = 0`（第1章の導入は読んだ扱い）にする。
- 初回ダイブのウミガメ配置（既存）はそのまま。

## 2. チュートリアルの新しい順序と表示位置

### 2.1 新しい順序（8 ステップ）

「撮る → 写真はお金になる → 2枚目以降のルール → エア → 浮上」の順。現行の 5・6（撮る・あと2種）を現行 4（エア）より前に移し、
お金の説明のあとにエアを置く。

| # | 表示文 | 完了条件 | 褒め |
| --- | --- | --- | --- |
| 1 | 画面の左側をドラッグして、前へ泳いでみよう | `moved > 4`（現行どおり） | いいね！ |
| 2 | 右側をドラッグして、まわりを見回そう | `looked > 1.6`（現行どおり） | その調子！ |
| 3 | ▼ボタンで、海底の近くまで潜ってみよう | **§2.3 の新条件** | 上手！ |
| 4 | 生き物を照準の枠に入れて、カメラボタンで撮ろう。近く・真横から・全身が入ると高評価 | `shots >= 1`（現行5） | ナイスショット！ |
| 5 | 撮った写真は、浮上したときに雑誌社が買い取ってくれる。評価が高いほど高く売れる。あと2種類、ちがう生き物を撮ってみよう | `species >= 3`（現行6） | すばらしい！ |
| 6 | 同じ生き物の2枚目以降は、図鑑の写真がより良い評価なら差し替わるが、売れるのは1回のダイブで1種1枚だけ。また売るには潜り直そう | 同じ種をもう一度撮る、または 9 秒読む（`hold`） | わかった？ 次はエアだ |
| 7 | 右上の丸いメーターがエア（空気）の残り。深く潜るほど、速く泳ぐほど早く減る。0になると気絶して救助され、稼ぎが減ってしまう。半分を切ったら戻り始めよう | 7 秒読む（現行4、`hold: 7`） | エアはいつも気にしておこう |
| 8 | ボートへ戻ろう。▲で水面近く（水深1.6mより浅く）まで上がると「浮上」ボタンが出る | `surfaceNear`（現行7） | 浮上ボタンを押してダイブ終了！ |

- HUD の強調（`hl-air` / `hl-surface`）は、ステップ番号の直書き（`T.step === 3`）をやめ、`TutStep` に `hl?: 'air' | 'surface'` を持たせて決める。
- `TutCtx` に `repeat`（このダイブで同じ種を2回以上撮った回数）を足す。撮影処理で、既に `pending` にある種を撮ったら `tut.repeat++`。

### 2.2 表示位置（画面中央を避ける）

- `#coach` を中央寄せから**左上**へ移す：`left: calc(12px + safe-left)`、`transform` なし、
  `top` は左上の HUD チップ（図鑑・売上）の下、幅 `min(340px, 44vw)`。照準（画面中央）と右上のエアメーター・右下のボタン群にかからない位置。
- 縦画面・狭い画面（幅 520px 以下）は、上端の HUD の下に横幅いっぱい（左右 12px）で出すが、文字を 13px に下げて高さを抑え、
  画面の上 1/3 に収める（照準の枠より上）。
- 実装時に Playwright で横（844×390）と縦（390×844）のスクリーンショットを撮り、照準・ボタンと重ならないことを確かめる。

### 2.3 チュートリアル3が一瞬でクリアになる問題

- **原因**：完了条件 `alt < 1.6 || depth > 6` が「今いる場所が海底に近い」だけで成立する。浅瀬ラグーンは水深 2–7m で、入水点（y=-3.2）
  やステップ1〜2で泳いだ先の海底が浅いと、ステップ3に入った最初のフレームで成立する。
- **修正**：「▼ボタンで潜った」ことを条件に入れる。ステップ3の間だけ `▼` を押していた秒数 `T.down` と、ステップ開始時の水深 `T.depth0` を記録し、
  `down >= 0.6秒 かつ（alt < 1.2 または depth >= depth0 + 1.5）` で完了。海底がすでに近い場所でも、▼を押せば完了できる。
- あわせて、褒め表示（1.4 秒）の間は次の判定をしない現行の仕組みはそのまま。

## 3. 2枚目以降の写真の説明（見切れ修正とチュートリアル化）

- 発見カードの文言を短くする：`このダイブでは売上済み（潜り直すとまた売れる）` → **`売上済み（1ダイブ1種1回）`**。
  `.disc-pay` は `white-space: normal` にして、万一長くても折り返す。

## 4. 時間システム

### 4.1 ルール

1. **浮上したら強制的に夜**：`endDive()`（浮上・気絶とも、大気圧潜水服の深海も含む）で `clock = max(clock, duskAt + duskLen)` にする。
   - 例外：食堂の「今日の仕込み：ウニ漁」（`quick` ダイブ）は店の用事として扱い、夜にしない → **確認が必要な点 A**。
2. **寝ると朝**：食堂（しおさい亭）で「朝にする（寝る）」を押すと `Kitchen.sleep()` が走り、翌日の朝（`clock = 0`、`day + 1`、注文の入れ替え、余った魚は市場へ）。
3. **水中ライト解放後は夜にもできる**：水中ライト（`torch`。強力ライトでも可、既存の `hasTorch()`）を持っていれば、朝〜夕方のときに「夜にする」で `clock = duskAt + duskLen`。
4. **単一ボタン**：食堂の `#k-sleep` を「時間ボタン」に作り替え、現在の時間で表示と動作が変わる。
   - 夜（`nightOf(clock) >= 0.5`）：「☾→☀ 朝にする（寝る）」→ 寝て翌朝へ
   - 昼で、ライトあり：「☀→☾ 夜にする」→ 夜へ
   - 昼で、ライトなし：ボタンを出さない
5. 旧仕様の「評判Lv3 で昼／夜を自由に選べる2ボタン」（`FISHING.nightFreeLevel`）は、単一ボタンに置き換えて撤去する（食堂の注文の魚の範囲を決める用途の `nightFreeLevel` は残す）。
6. ボート画面の時間パネル（`renderDaytime`）は表示と案内だけにする。夜でライトがないときは「夜の海はライトがないと潜れない。しおさい亭で休むと朝になる」と `しおさい亭へ帰る` ボタン。
7. 潜水中に時間が進んで夕方・夜になる既存の仕組み（`clock` の加算）はそのまま。

### 4.2 しおさい亭を最初から使えるようにする（泊まっている設定）

- `#open-kitchen` を最初から表示（チュートリアル後）。表示名は「しおさい亭（宿）」、夜は「休む」バッジ。
- 手銛を持つまでの食堂画面は「宿」としての表示だけ：女将さんの一言（§6）・時間ボタン。注文・クーラー・店の仕事・まかないの欄は手銛を持つまで隠す。
- 手銛購入後は現行どおり注文が出る（＝「銛が解放されたら、途中から食堂で依頼を受ける」）。`STORY[0]` の文は、すでに顔見知りの女将さんが頼む形に書き直す。

## 5. 冒頭ストーリーと編集長の依頼の報酬

### 5.1 流れ

1. **プロローグ（`CHAPTERS[0].intro`、海中で表示）**：
   主人公はもともと趣味で潜り、海の中の写真を撮っていたダイバー。ネットに載せていた写真が海洋雑誌『月刊うみなか』の編集長の目に留まり、
   「腕を見せてほしい」とこの島に呼ばれた（スカウト）。泊まる所は港の食堂「しおさい亭」を手配してある。まずは浅瀬で試し撮り。
2. **チュートリアル**＝試し撮りのダイブ。
3. **浮上後（ボート画面）**：第1章クリアの表示に、編集長の褒め言葉を出す：
   「流石だな。噂どおりの腕だ。写真、全部買わせてもらうよ」。`Chapter` に `praise?: string` を足し、`storyCleared` の行に出す。
4. **仕事の依頼（`CHAPTERS[1].intro`）**：褒める流れから「正式に仕事を頼みたい。報酬は章ごとに払う」と依頼。目標と報酬額をカードに明示する（`sc-goal` に「報酬 ¥…」）。

## 6. 女将さん（ハルさん）のセリフ

`kitchen.ts` に `okamiLine()` を足し、しおさい亭の画面の上部（新規 `#k-okami`、吹き出し）に一言を出す。新しいセーブ項目 `okami?: { lore: number; seen?: string }`。

### 6.1 場面ごとの一言（毎回変わる、短い）

- **帰ってきたとき**（ダイブ後に初めて食堂を開いた）：「おかえり。今日はどうだった？」「おかえり、冷えたろう。お茶があるよ」など数種からランダム。
  新種を撮って帰った日は「いい顔してるね。いい写真が撮れたんだろう」系。
- **朝**（寝て起きた直後）：「おはよう。今日もいい凪だよ」「おはよう。朝ごはんはしっかり食べていきな」など。
- **夜でライトがない**：「夜の海は暗くて危ないよ。今日はもう休みな」。

### 6.2 世界観の小分け説明（1回の訪問で1つだけ、順番に、条件を満たしたら）

| 段階 | 条件 | セリフ（要旨） |

## 7. セーブ形式

キーは `blue-depths-save-v1` のまま。追加する項目はすべて省略可能（`okami`、`boardOn`、`boardIntro`）で、旧データはそのまま読める。
`loadSave()` で、既存セーブ（`dives > 0`）は `boardOn = true`、`okami.lore` は 1（自己紹介は済み扱い）とする。版上げは不要。

## 8. テスト（ステップ2の確認方法）

## 9. 確認が必要な点（勝手に決めずに記録）

- **A** 食堂の「ウニ漁」（店の前の岩場へ行く短いダイブ）も浮上後に夜にするか。Phase 1 では、朝の仕込みが終わると一日が終わってしまうのを避けるため夜にしない実装にした。
- **B** 「銛が解放されたら、途中から食堂で依頼を受ける」は、手銛購入後に食堂の注文（伝票）が出ることとして実装した。掲示板の島民の依頼まで食堂に移す意味だった場合は Phase 3 で対応する。
- **C** 章の報酬額（§5.2）は仮。Phase 2（写真報酬 1/7）と Phase 11 で見直す。
- **D** 掲示板の解禁を「2日目の朝」にしたこと。
