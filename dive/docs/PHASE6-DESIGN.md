# Phase 6 設計：ダイビングシステム・水深・エア・アクティビティ

設計：Muse（分担方針により Muse が設計・実装とも担当）。トラッカー Phase 6 の全項目が対象。
数値・解釈の暫定決定は §7（AH〜AM）。いずれも進行を止めない。

## 0. 監査結果（現状コードの事実）

- **水深表示**：`updateHud` が `d = -camera.position.y`（カメラ＝頭の位置）をそのまま表示。最大水深も同じ定義。
- **エア表示**：bar の数値＋リングゲージのみ。持続時間（分）の表示はコード内に存在しない（Phase 2 で bar 表示に統一済み）。
- **窒素酔い**：`narc = clamp((d - 40) / 18, 0, 1)`（40m で開始、58m で最大）。効果は分散している：カメラの横揺れ（roll sin・0.08・narc）、エア消費 ×(1 + 0.5・narc)、撮影のシャープ距離 ×(1 − 0.3・narc)、紫のオーバーレイ（opacity 0.8・narc）、警告文「窒素酔い注意」（40 < d ≤ 52 のときのみ表示。52m 超は「限界深度に接近」が優先）。プレイヤーには「何が危ないか」が読み取れない。
- **浮上**：ポーズ画面の「浮上して終了」（#abort）は `surfaceAnywhere()`（シグナルフロート所持）のときだけ表示され、クリック側でも再確認する（Phase 2 で実装済み）。
- **ライト・時間帯**：ライトの解放は図鑑 45 種（Phase 2）。時間は `save.clock`（連続時計）＋ `nightOf(clock)`（0.5 以上で夜）で管理され、夜はライトなしでは潜れない（`nightBlocked()`）。ただしプレイヤーが自由に時間帯を切り替える手段はない（ストーリー進行で進むのみ）。
- **ウニ漁**：食堂からのクイックダイブ（岩礁ポイントへ直接開始、終了後はタイトルを経て食堂キッチンを開く）。制限時間 80 秒、必要 8pt。配置：ムラサキウニ 6（1pt）、アカウニ 3（2pt）、ラッパウニ 3（毒）、ガンガゼ（毒）。食用の最大は 6×1 + 3×2 = 12pt。

## 1. 水深表示・潜水姿勢

### 1.1 解釈
トラッカーの4項目は「表示の水深より浅く感じる」「人間の体は地面に水平」「体の幅・長さを考慮して表示を修正」「必要に応じて海を深くする」。
現行表示は頭（カメラ）の水深。人間は水平姿勢で全長約 1.7m（頭からフィン先）、胴の厚み約 0.35m ある。頭だけの水深は、体の中心やフィンの水深と姿勢（ピッチ）次第で最大 ±0.85m ずれる。表示を体の中心に合わせるのが「幅・長さを考慮」の実装上の意味と解釈する（AH）。

### 1.2 変更
- 表示水深・最大水深を **体の中心の水深** に変える：`d = -p.y + sin(pitch) * 0.85`。pitch はカメラのピッチ（頭が上を向いている＝上昇姿勢のとき中心は頭より深い）。符号：`pitch = -camera.rotation.x`（rotation.x が負＝上向き）。クランプは 0 以上。
- 図鑑の「撮影水深」は被写体（魚）の深さ（takePhoto の depth = -t.agent.p.y）であり、ダイバーの表示とは別物なので変更しない。
- 環境の減光は既に exp(-depth/40) で効いている（environment.ts:349）ため、光のカーブは変えない。
- **海自体は深くしない**（AI）：Phase 5 で地形・種の分布・バランスを現行の水深で確定したばかりで、再スケールは影響が大きすぎる。「必要に応じて」は §1.2 の表示修正で対応し、実機でまだ浅く感じる場合は Phase 11（総合確認）で再検討する。要確認事項に記録し、ユーザ確認リストに体感確認の項目を入れる。

## 2. エア表示
現状（bar 数値＋リングのみ、持続時間の表示なし）がトラッカーの要求どおりであることを確認して閉じる。あわせてショップ・装備の説明文に持続時間（分）の表現がないか最終確認し、あれば bar 表現に置き換える。

## 3. 窒素酔い（明確なリスク化）

現行の分散した効果は残しつつ、段階のある「読み取れるリスク」を追加する（AJ）。

- **警告の具体化**：40m 超の警告文を「窒素酔い注意」から「窒素酔い：エア消費増・視界が揺れる」に変える（52m 超の「限界深度に接近」は現行どおり優先）。
- **第2段階（narc ≥ 0.55、約 50m〜）：方位感覚の喪失**。HUD の方角表示が数秒ごとに一瞬ブレる（誤った方角を 0.4 秒表示して戻る）。ミニマップの自機矢印も同じタイミングでずれる。操作入力には干渉しない（理不尽さを避ける）。
- **第3段階（narc ≥ 0.83、約 55m〜）：ブラックアウト**。この深さ帯にいる累計時間が 10 秒に達すると意識を失い、救助されてボートに戻る。帰結は既存のエア切れブラックアウトとそろえる（このゲームの原則「発見は失われない。代わりに救助費用がかかる」に従う）：写真の記録は残るが売上は PHOTO.blackoutKeep の割合に減り、獲物と未開封の拾い物は失う。結果画面には窒素酔い専用の文面を出す（endDive の reason に 'narcosis' を追加し、金額・獲物の扱いは 'blackout' と同じにする）。5 秒経過時点から前兆として画面端のビネットを強める（#narc オーバーレイの縁を濃くする）。
- ADS ダイブは現行どおり窒素酔い無効。カウントは narc が下がれば徐々に回復する（−2/秒）。

## 5. 水中ライト・時間帯変更ボタン

監査の結果、**この節は実装済み**だった（食堂の時間ボタン #k-sleep、kitchen.ts:244-246）：
- ライト未所持の昼間はボタン自体が隠れる（＝ライト解放後に「夜にする」が出現する）。
- 昼は「☀→☾ 夜にする」、夜は「☾→☀ 朝にする（翌日の朝へ）」と、現在の時間帯でラベルと動作が切り替わる。
- ライトの解放は図鑑 45 種（Phase 2）＝中盤の解放として現状維持。

→ Phase 6 ではプローブで3状態（ライトなし昼／ライトあり昼／夜）を確認して閉じる。新規実装はしない。

## 6. ウニ駆除・ウニ漁

- **制限時間**：MISSION.urchin.time を 80 → **150 秒**（AL）。
- **配置数**：URCHINS の n を ムラサキ 6→12、アカ 3→6、ガンガゼ 4→5、ラッパ 3→4（合計 16→27、食用の最大 12→24pt）。散布半径は `3 + sqrt(rand) * 24` → `* 32` に広げ、最小間隔 3.2m は維持する。InstancedMesh の個数は n から自動で決まる。
- **導線**：食堂のウニ漁は既にクイックダイブで直接開始される（開始導線は現状で充足）。ボード依頼のウニ駆除も同じ MISSION.urchin の数値を使うため、時間・配置の改善は両方に効く。
- **終了後の戻り先**：クイック漁の終了処理（endDive の quick 分岐）は現在つねに食堂キッチンを開く。ダイブ開始前と終了後で時間帯（nightOf >= 0.5 かどうか）が変わっていたら、キッチンを開かずタイトル（メニュー）に戻す。開始時点の夜フラグを quick に持たせて比較する。

## 7. 暫定決定（要確認事項へ AH〜AM として追記）

- AH：水深表示の「体の中心」は、全長 1.7m の水平な体の中心（カメラから 0.85m）としてピッチで補正する解釈にした。
- AI：海自体を深くする再スケールは行わない（Phase 5 のバランスを優先）。体感がまだ合わなければ Phase 11 で再検討。
- AJ：窒素酔いのリスクは「方位の喪失（50m〜）」と「ブラックアウト（55m〜・累計10秒）」の2段階で具体化した。帰結は既存ブラックアウトと同等。
- AK：（監査で不要になった）時間帯ボタンは食堂に実装済みだったため新規には作らない。
- AL：ウニ漁の制限時間は 150 秒、必要ポイントは 8pt のまま（配置増で難易度は下がる方向）。
- AM：ウニ漁の終了後、時間帯が変わっていた場合は「メニュー画面」＝タイトル画面に戻る、と解釈した。
