# Phase 7 設計：UI・図鑑・メニュー・操作性

設計：Muse。トラッカー Phase 7 の全項目が対象。暫定決定は §7（AN〜AQ）。

## 0. 監査結果（現状コードの事実）

- **表示の大きさ**：HUD は 2026-11-25 の2弾で拡大済み。食堂・図鑑・ショップ側には 10.5〜12px の小さい文字が残る（`.gear-item .req` 10.5px、`.gear-item` 11px、`.dcard .nm` 12px、`.pt .sb` 12px など）。
- **写真→図鑑**：結果画面の写真カード（`.res-card`）にも発見カード（`#disc`）にも、図鑑への導線はない。`openDex()` は一覧を開くだけで、詳細（`showDetail(id)`）への直接遷移は未配線。
- **メニューのネタバレ**：タイトルの目標表示（`goalText`）は、図鑑が足りない場合は「？」だが、お金が足りない場合は商品名を出す（`「${gl.name}」まであと ¥…`）。買える場合は名前＋「買える！」。
- **ショップの点滅**：購入可能アイテムは Phase 2 で「点滅させず明るく表示」に変更済み（styles.css:195 のコメントと `.gear-item.can` の静的スタイル）。点滅アニメーションは警告系（水深警告・エア危機）だけに残る。
- **まかない説明**：食堂の `#k-buff` は、バフがないときに説明文「まかない（自分で食べる料理）を食べると、次のダイブが少し楽になる。」を表示する。食堂の一番下のブロック。
- **チュートリアル**：教示文は `#coach`（上部固定）。≤560px では top: 206px・全幅で、長い文だと画面中央近くまで垂れる。2枚目の説明文（story.ts:134）は「また売るには潜り直そう」で文が途切れている。
- **イベント残り時間**：Phase 3 で、円の外では残り時間を表示せず「金色の円の中へ」に変え、バーも隠す実装になっている（missions.ts renderHud）。
- **デバッグボタン**：「進行度0にする」「全部解禁済みにする」はどちらも `window.confirm` で確認する。アーティファクト（iframe）環境では confirm がブロックされ、無反応に見える。

## 1. 表示の大きさ・読みやすさ（残りの画面）

食堂・図鑑・ショップ・タイトルの小さい文字を +1〜1.5px する：`.gear-item` 11→12.5px、`.gear-item .req` 10.5→12px、`.dcard .nm` 12→13px、`.dz-title` 13→14px、`.dd-zone` 12→13px、`.dd-meta` 12.5→13px、`.pt .sb` 12→13px、食堂 `.k-item .who`（現行値を確認して +1px）。レイアウトが崩れない範囲に留め、図鑑グリッドは 390px 幅で目視確認する。

## 2. 写真・図鑑

- **写真タップ→図鑑**：`openDex(id?)` に引数を足し、id があれば一覧を構築した直後に `showDetail(id)` を開く。結果画面の `.res-card` に `data-dex` を付けてクリックで `openDex(id)`。発見カード（`#disc`）は表示中の種 id を `dataset.dex` に持ち、タップで `openDex(id)`（カードは即座に隠す）。宝箱カード等の別用途では dataset を消す。
- **サンゴやヤギなど**：ヤギ＝ヤギ類（ゴルゴニアン）を含む固着性の生き物と解釈する（AN）。図鑑は既に無脊椎動物（クラゲ・ヒトデ・ナマコ・ウミウシ・貝・ウミシダ・イバラカンザシ等）を広く収録しているが、サンゴ・ヤギ類そのものは景色（flora のインスタンス）で、撮影対象の個体として存在しない。個体モデルと配置が要る新規の生物追加なので、**Phase 12（生物追加）で扱う**。トラッカーにはその旨を注記し、項目は開いたままにする（Phase 5 の AD と同じ扱い）。

## 3. メニュー画面のネタバレ防止

`goalText` のお金不足の分岐も商品名を出さず「？」にする（`「？」まであと ¥…`）。買える分岐（名前＋「買える！」）は、入荷済みで今買えるものの案内であり「入荷まであと」の表示ではないため現行どおり（AO）。

## 4. ショップ表示

現行（Phase 2 の変更）を確認して閉じる。検証は CSS の静的確認＋プローブで `.gear-item.can` の computed animation-name が none であること。

## 5. 食堂表示

`#k-buff` のバフなし時の説明文を出さない（空にする）。バフ有効時の状態表示（「次のダイブ：まかないの〜で…」）は説明ではなく状態なので残す。

## 6. 表示・操作上の不具合

- **チュートリアルの位置**：≤560px では `#coach` を HUD の直下（`top: calc(118px + var(--safe-t))`）に寄せる（AP）。中央の視界（照準と魚）を空ける。当初案は下部（`bottom: calc(168px + var(--safe-b))`）だったが、実装中に HUD 直下へ変更した（AP）。マップ発見バナー `#map-found` は、コーチ表示中は `top: 272px` まで下げて重ならないようにする。
- **2枚目の説明の見切れ**：story.ts:134 の文を完結させる（「また売るには潜り直そう」→「また売るには潜り直す必要がある」）。あわせて §6 の位置変更で、長い文が中央に垂れなくなる。
- **イベント残り時間**：Phase 3 の実装（円の外では時間を表示しない）を確認して閉じる。プローブで円の内外の表示を確認する。
- **デバッグボタン**：`window.confirm` をやめ、2回タップ式にする（AQ）。1回目のタップでボタン自体が確認文言（「本当にリセットする？」等）に変わり、3.5秒以内にもう一度タップすると実行する。時間切れでラベルは元に戻る。

## 7. 暫定決定（トラッカー未解決事項へ AN〜AQ として追記）

- AN：サンゴ・ヤギ類（固着性の生き物）の図鑑追加 → 暫定：Phase 12（生物追加）で扱う。現状は景色（flora）で撮影対象の個体モデルと配置がなく、新規の生物追加になるため。トラッカーの項目は開いたまま注記する。
- AO：メニューのネタバレ防止は「買える！」の案内には適用しない → 暫定：入荷済みで今買えるものの案内であり、「入荷まであと」の表示ではないため名前のまま。伏せるのは図鑑不足・お金不足の両方。
- AP：チュートリアルの教示の位置 → 暫定：小画面（≤560px）では上部（HUD の直下、top 118px）に置く。当初の下部案から実装中に変更（§6）。
- AQ：デバッグボタンの確認 → 暫定：`window.confirm` を使わず、ボタン自体が確認文言に変わる2回タップ式（3.5秒有効）。アーティファクト（iframe）では confirm がブロックされるため。
