# BLUE DEPTHS — 海へ潜る (Design Brief)

参考スキル: majidmanzarpour/threejs-game-skills
(threejs-game-director / gameplay-systems / aaa-graphics-builder / game-ui-designer / qa-release)。
アセットはすべて手続き生成（テクスチャ・モデル・音）。外部API・有料素材なし。

## Design brief
- **Player promise**: 一人のダイバーとして、浅いラグーンからサンゴ礁・岩礁・沖の大海原・深海まで潜り、海の生き物たちに出会って写真図鑑を埋める。
- **Target feeling**: 光と静けさ、浮遊感、巨大生物と出会う畏怖、深海の暗闇と生物発光の神秘。
- **Primary verb**: 泳ぐ（視線方向へ進む）。
- **Secondary verbs**: 撮る（シャッター）、照らす（ライト）、浮上する。
- **5–30秒の反復**: 生き物を探して近づき、フレームに収めて撮影。
- **1–5分の変化**: エア残量が減る（深いほど速い）。新種を撮るほど装備が解放され、行けるエリアが広がる。
- **失敗・学習・再挑戦**: エア切れで気絶 → 救助され、その潜水で撮った未保存の写真は失われる。浮上すれば保存。
- **報酬とリスク**: 深く・遠くほど珍しい生き物がいるが、エア消費が増える。
- **上手いプレイヤー**: エア配分を考え、生き物の生息環境（イソギンチャク・岩の隙間・砂地・中層）を読んで効率よく撮影する。
- **次の判断の伝え方**: HUDの深度・エア計・ゾーン名、図鑑の「生息域ヒント」、生き物の近くでレティクルが反応。
- **Non-goals**: 戦闘、減圧計算の厳密シミュレーション、水面上の世界。

## Core loop contract
ダイバーは **泳いで撮影** し、**図鑑を埋める**。**エア残量（深度で消費増）** がリスクを生む。
成功（浮上）で写真が図鑑に保存され、発見数に応じて装備（フィン・大型タンク・スクーター・大気圧潜水服）が解放される。
失敗（エア切れ）はその潜水の未保存写真を失い、ボートで再出発。

## Level plan（岸から沖へ z+ 方向）
| ゾーン | 範囲 | 水深 | 主な生き物 |
| --- | --- | --- | --- |
| 浅瀬ラグーン（砂地・海草） | z -60〜120 | 2〜7m | チンアナゴ, アカエイ, ヒラメ, ハコフグ, アオウミガメ |
| サンゴ礁 | z 120〜340 | 6〜16m | クマノミ, ナンヨウハギ, ツノダシ, チョウチョウウオ, ブダイ, デバスズメダイ, ハナミノカサゴ |
| 岩礁（x>50） | z 40〜340 | 8〜25m | ウツボ, イセエビ, マダコ, イシダイ, ウミウシ, ネムリブカ |
| ドロップオフ〜沖 | z 340〜720 | 15〜170m | イワシの群れ, マグロ, マンタ, ジンベエザメ, シュモクザメ, イルカ, クジラ, ミズクラゲ |
| 深海 | z 720〜 | 170〜430m | アトラクラゲ, チョウチンアンコウ, ダイオウイカ, リュウグウノツカイ, メンダコ, ダイオウグソクムシ, ハオリムシ（熱水噴出孔） |

- スタート: ボート上で潜水ポイントを選択（深海は大気圧潜水服が必要）。
- ランドマーク: ボートの船底と係留ロープ、サンゴの根、岩のアーチ、ドロップオフの壁、沈没船、熱水噴出孔。
- 圧力: スキューバは 40m を超えると窒素酔い（視界ゆがみ・エア消費増）、60m で限界。

## Art direction
フォトリアル寄りの水中表現。方向依存の水中フォグ（上は明るく下は暗い）、深度による赤色減衰、
コースティクス（地形・サンゴ・岩に投影）、光芒、マリンスノー、スネルの窓、泡。
深海は真っ暗でダイバーライトと生物発光のみ。

## Render budget (mobile)
DPR ≤ 1.5 かつ画素数 90 万以下、ポストプロセスなし（ビネット/マスクはCSS）、太陽の影は近くのものだけ、描画距離はフォグで制限、
地形はチャンク化し周辺のみ生成、群れは InstancedMesh + 頂点シェーダで泳ぎアニメ。数値の予算は `docs/PHASE8-DESIGN.md` §6.1。

## 調整メモ（「桜井政博のゲーム作るには」を参考に: 原則 → 問題 → 直したこと）
- **手触りを守る（実機で重い）**: 画面幅の指定がない版はスマホで約9.5倍の画素を描き、影・遠くのサンゴ・小物にも近景と同じ手間をかけていた。→ 画素数に上限を付け、見える差の小さいところから削った（影は近くだけ、遠くは簡易な形、小物は結合、離れた生き物は破棄と間引き、シェーダは暗転中に準備）。撮影・餌・タコなど遊びの判定に関わる個体は間引かない。
- **リスクとリターン（ナイトダイブ）**: 夜は夜間手当×1.3で稼げるのに、何も危険がなかった。→ 夜の海は「水中ライト」（¥800、強力ライト所持でも可）がないと潜れず、買えないときは「朝まで休む」で翌朝へ。夜は昼の魚が眠って出現が4割になる（`NIGHT.dayPresence`、レア度1は最低1群を残す）。浅場（水深8m以浅）ではオキザヨリがライトに反応し、0.8秒ためてから一直線に突進する（`aggro.kind: 'light'`。突進中にライトを消すと外れる）。見返りに夜専用の生き物を10種（ゴシキエビ、ウチワエビ、ミズヒキガニ、オドリカクレエビ、ヒメイカ、ベニテンジクダイ、シモフリタナバタウオ、イソカサゴ、ホタルジャコ、ミナミイスズミ）と夜だけの特別な光景3つ（ライトに集まるマンタ、ハダカイワシの鉛直移動、ヒカリキンメダイの明滅）を足した。
- **連写で無限に稼げる→1ダイブ1種1回**: 同じ種を何枚でも撮って、より高い評価で売上を上書きできた。→ 売上は最初の1枚で確定、2枚目以降は0円（`PHOTO.oncePerDive`）。より良い写真は図鑑の記録だけを更新し、発見ポップアップに「このダイブでは売上済み」と出す。潜り直せばまた売れる。
- **行いには報いを（助けたウミガメが消える）**: 網を切ったウミガメが画面から消えて終わり、助けた実感が薄かった。→ そのダイブの間、右前方をついてくる（`Creatures.companion`）。写真も撮れる。ダイブを終えると居なくなる。
- **遠くのものは遠く見せる（海面が近すぎる）**: 水深10〜20mから見上げた海面が、すぐ頭上にあるように見えた。→ 海面の色を距離で水の色に溶かし、波の揺らぎをぼかし、窓の縁をぼかし、水深で暗くした（`environment.ts` の海面シェーダ）。水深1〜3mの見た目はほぼそのまま。
- **最初の30秒で遊ばせる（いきなり海の中）**: 新しく始めると、まずボート画面の文字とボタンを読まされた。→ ローディングの直後に浅瀬ラグーンの海の中から始め、プロローグ（趣味の写真が編集長の目に留まって島に呼ばれた）を海の景色の上に重ねる。最初のタップで音を出し、そのまま試し撮りのチュートリアルへ（`Game.start()` → `startDive(…, prologue)`）。
- **教える順番（お金→エア）**: エアの説明が撮影より先で、何のために時間を気にするのか分からなかった。→ 撮る → 写真は浮上すると売れる（3種撮る）→ 2枚目以降は1ダイブ1種1回 → エア → 浮上、の順にした（`TUTORIAL`）。2枚目以降のルールは発見カードの長い文（見切れていた）から、チュートリアルの1ステップに移した。
- **できたことをほめる（チュートリアル3が一瞬で終わる）**: 浅瀬では「海底に近い」が最初から成立し、▼を押す前にクリアになっていた。→ ▼を0.6秒以上押したうえで海底に近づく（または1.5m潜る）ことを条件にした。
- **画面の中央はプレイヤーのもの**: チュートリアルの吹き出しが照準の近くに出て邪魔だった。→ 画面の上端中央（縦画面はミニマップの下）に移し、文字を小さくした。
- **報酬は約束どおりに（編集長の依頼）**: 試し撮りと、特別な光景を撮る2つの章は報酬が0円だった。→ すべての章に報酬を付け、課題カードに金額を出し、クリア時に編集長の褒め言葉と一緒に表示する（金額は仮。Phase 2/11 で調整）。
- **場所に愛着を（しおさい亭）**: 食堂は手銛を買うまで存在せず、時間の区切りもボートのボタンだった。→ 最初から泊まっている宿にし、浮上すると夜、寝ると朝。女将さんが帰りと朝に一言くれて、島の不思議を1回に1つずつ話す（全部まとめて言わない）。時間のボタンは1つで、今の時間に合わせて「朝にする」「夜にする」が入れ替わる。
- **ご褒美は手渡しで（Phase 3、編集長の報酬）**: 章の報酬が黙って所持金に足され、受け取った実感がなかった。→ クリアで「受け取る」ボタンが章カードに出て、押すとお金が増える音と表示。受け取り忘れで進行は止めない。詳細は `docs/PHASE3-DESIGN.md`。
- **達成は必ず伝える（Phase 3、新マップ通知）**: 通知が1枠のトーストで上書きされていた。→ 専用バナーとキュー、`visited` で「初めて入った」を記録。
- **待ち時間を見せるのは意味がある所だけ（Phase 3、残り時間）**: 円の外でも「残り◯秒」が減っていた。→ 円の中だけで表示し、時間も円の中でだけ進める。
- **押したら動く（Phase 3、ウミガメ）**: 網のそばで3秒じっとするだけだった。→ タップでナイフを3回振るモーション、網が裂けて消える。
- **プレイヤーに発見させる（Phase 5、海図）**: 原則「探す楽しさを残す」→ 問題：海図に遺跡の四角や洞窟の通路がそのまま描かれ、行く前に答えが分かってしまった → 地図専用の自然地形（`chartHeightAt`）で描き直し、航空写真風（水の色が深さで海底を覆い、海底の色は浅い所だけ透ける）にした。人工物・洞窟の通路・沈没船の掘れ跡は描かない。ブルーホールの円とセノーテの点は自然地形として出す（確認点X）。
- **数を見せない（Phase 5、未発見の扱い）**: 「あと○か所」と分かると探索が作業になる。→ ボートの未発見ポイントは常に「×？」、アルバムも分母を「？」にし、未発見マップの写真スポットは行ごと出さない。宝箱のヒントで名前が出た光景だけ、アルバムに名前と手記が出る。
- **端は理由と一緒に止める（Phase 5、マップ端）**: 端が黒い壁だと世界の外を感じさせる。→ 海図に余白120mを足して海（南だけ浜と陸）が続くように描き、実際に行くと潮の流れで押し戻され、壁際で「これ以上は進めない」と理由が出る。
- **形は名前どおりに（Phase 5、遺跡と洞窟）**: 遺跡が段々の台地でピラミッドに見えず、洞窟は上から見ると穴が空いていた。→ 正方形5段＋大階段＋頂上の神殿（太陽のピラミッド）にし、洞窟は地形メッシュが天井の上を覆う（`surfaceTopAt`）＋内側に床のリボンを別に敷いた。洞窟の上の台地にも砂地の魚を置いた。
- **ご褒美は探した先に（Phase 5、宝箱）**: 各マップに宝箱1つ（全10個）。沈没船・神殿・洞窟の奥は店で買えない限定装備、他は未撮影の光景の手記のヒント。光景を全部撮った後の箱は銀貨になる。
- **粒子は深さの合図（Phase 5、マリンスノー）**: 浅い沖でも白い粒が見え、深海に入った感じがしなかった。→ 120mから出始め170mで最大にし、浅場とブルーホール（55m）では消した。夜光虫の青い光は別の効果として残す。
- **固有種は数えてから動かす（Phase 5）**: 遺跡3・ブルーホール5・洞窟3しか固有魚がいなかった。→ 「出現位置の80%以上がそのマップ」で数え直し、既存種の所属移動で全マップ10種以上にした（新種の追加は Phase 12）。
- **水深は体の中心で測る（Phase 6、水深表示）**: 表示が頭（カメラ）の位置で、水平に泳ぐ体の中心と姿勢によってずれていた。→ 全長約1.7mの体の中心（目の0.85m後方、ピッチで補正）の水深を表示と判定に使う。海そのものの再スケールは Phase 5 のバランスを壊すのでしない。
- **窒素酔いは段階で読めるリスクに（Phase 6、窒素酔い）**: 揺れ・エア増・撮影距離減が分散していて、何が危ないか読み取れなかった。→ 警告文を具体化し、50m〜で方位の計器がブレる（方位感覚の喪失）、55m〜に累計10秒でブラックアウト（救助。帰結はエア切れと同じ）を追加した。
- **ウニ漁は時間と数を増やし、戻り先は時間ボタンで変える（Phase 6、ウニ漁）**: 80秒・16個では短く少なく、終わった後に食堂で朝や夜にしても食堂に留まっていた。→ 150秒・27個に増やし、ウニ漁の直後に食堂の時間ボタン（朝にする／夜にする）を押したら、食堂を閉じてメニュー（タイトル）に戻す。
- **写真は図鑑への近道（Phase 7、写真・図鑑）**: 撮った写真を見ても、その魚の図鑑ページへ行く手段がなかった。→ 発見カードと結果画面の写真カードをタップすると、その種の図鑑ページを直接開く。
- **メニューでは未購入の装備名を出さない（Phase 7、ネタバレ防止）**: 目標表示が次に買える装備の名前を出し、入荷の楽しみを先取りしていた。→ 「入荷まであと」の表示は図鑑不足でもお金不足でも「？」にし、名前は入荷して買える状態になってから出す。
- **確認ダイアログはゲームの中で（Phase 7、デバッグボタン）**: window.confirm はアーティファクト（iframe）環境でブロックされ、ボタンが無反応に見えた。→ 確認はボタン自体が確認文言に変わる2回タップ式にする。ブラウザ標準のモーダルに頼らない。
