# BLUE DEPTHS

スマホブラウザ向けの3Dダイビング＆写真図鑑ゲーム（Three.js / TypeScript / Vite）。
浅瀬ラグーン・サンゴ礁・岩礁・ドロップオフ／沖・深海の5エリアで、150種の生き物を撮影して図鑑を埋める。
モデル・テクスチャ・音はすべて手続き生成（外部API・有料素材なし）。設計は `DESIGN.md`。

- 浅場の魚の種類と配色は quiz リポジトリの `images/`（沖縄の浅海魚の写真）を参考に作成（写真そのものは使っていない）。
- 岩肌・砂地・サンゴのポリプ・ノウサンゴの模様は `scripts/gen_textures.py`（numpy）で焼いた法線＋アルベドのタイル画像を、トライプラナーで貼っている。
- 魚は生態ごとの「くらし（マイクロハビタット）」を持つ：枝サンゴの上に浮かぶ／サンゴをついばむ／テーブルサンゴの下に潜む／サンゴや岩の上にとまる／砂地の巣穴でホバリング／砂地すれすれで採餌／礁縁の中層で群れる／壁沿い／水面直下／海草藻場／クリーニングステーション など。

## 遊び方
| 操作 | スマホ | PC |
| --- | --- | --- |
| 泳ぐ（視線方向） | 画面左側をドラッグ | WASD |
| 見回す | 画面右側をドラッグ | マウスドラッグ |
| 浮上／潜降 | ▲▼ボタン | Space / Shift |
| 撮影 | カメラボタン | E |
| ライト | ライトボタン | L |
| 図鑑 | 右上の図鑑 | M |
| マップ | 左上の丸いミニマップをタップ | N |

- エアは深いほど速く減る。エア切れで気絶すると、その潜水の写真は失われる。浮上すると図鑑に登録。
- 図鑑5/12/22/35種でフィン・大型タンク・水中スクーター・大気圧潜水服（深海解放）を入手。

## 開発
```
npm install
npm run dev        # http://127.0.0.1:5190
npm run artifact   # dist/artifact.html（1ファイルにインライン化）
python3 scripts/gen_textures.py   # 表面テクスチャの再生成
```
