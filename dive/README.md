# BLUE DEPTHS

スマホブラウザ向けの3Dダイビング＆写真図鑑ゲーム（Three.js / TypeScript / Vite）。
浅瀬ラグーン・サンゴ礁・岩礁・ドロップオフ／沖・深海をはじめ海藻の森・洞窟・ブルーホール・遺跡など多数のエリアで、600種の生き物（魚＋ナマコ・ヒトデ・ウニ・シャコガイ・イバラカンザシ・ウミシダ・エビ・ヤドカリ・ウミヘビ・ウミウシ・クラゲ・クシクラゲ・ヒカリボヤ・ウミユリなど）を撮影して図鑑を埋める。
モデル・テクスチャ・音はすべて手続き生成（外部API・有料素材なし）。設計は `DESIGN.md`。

- 浅場の魚の種類と配色は quiz リポジトリの `images/`（沖縄の浅海魚の写真）を参考に作成（写真そのものは使っていない）。
- 砂地・サンゴ礫・礁の基盤・岩・沈没船の錆は Poly Haven の CC0 実写PBRテクスチャ（`scripts/prep_pbr.py` で整形、出典は `src/assets/tex/CREDITS.md`）。サンゴのポリプ・ノウサンゴの模様は `scripts/gen_textures.py`（numpy）で焼いた法線＋アルベドのタイル画像を、トライプラナーで貼っている。
- 大型〜中型の魚31種（ジンベエザメ・サメ類・メガネモチノウオ・カジキ・アジ類・ハタ・ベラ・タイなど）は、Wikimedia Commons の**パブリックドメイン／CC0**の写真・博物画を `scripts/photo_fish.py`（rembg IS-Net で切り抜き→色補正→シルエット抽出）で加工し、写真の輪郭から胴の厚みを推定したメッシュに貼っている。出典は `src/assets/fish/CREDITS.md`、採用写真と処理設定は `scripts/photo_fish_picks.json`。
- 魚は生態ごとの「くらし（マイクロハビタット）」を持つ：枝サンゴの上に浮かぶ／サンゴをついばむ／テーブルサンゴの下に潜む／サンゴや岩の上にとまる／砂地の巣穴でホバリング／砂地すれすれで採餌／礁縁の中層で群れる／壁沿い／水面直下／海草藻場／クリーニングステーション など。

## 遊び方
| 操作 | スマホ | PC |
| --- | --- | --- |
| 泳ぐ（視線方向） | 画面左側をドラッグ | WASD |
| 見回す | 画面右側をドラッグ | マウスドラッグ |
| 浮上／潜降 | ▲▼ボタン | Space / Shift |
| 撮影 | カメラボタン | E |
| ライト | ライトボタン | L |
| 図鑑 | 右上の図鑑 | M |
| マップ | 左上の丸いミニマップをタップ | N |

- エアは深いほど速く減る。エア切れで気絶すると、その潜水の写真は失われる。浮上すると図鑑に登録。
- 図鑑5/12/22/35種でフィン・大型タンク・水中スクーター・大気圧潜水服（深海解放）を入手。

## 開発
```
npm install
npm run dev        # http://127.0.0.1:5190
npm run artifact   # dist/artifact.html（1ファイルにインライン化）
python3 scripts/gen_textures.py   # 表面テクスチャの再生成
```

## 撮影の判定
写真として認められるのは次の条件をすべて満たしたときだけ：写真の切り出し範囲に入っている／画面の6%以上の大きさで写っている／水の濁りで霞まない距離（視程から計算）／地形に隠れていない／深海ではライトの照射範囲内か自ら発光している。

## ゲーム性の設計メモ（「桜井政博のゲーム作るには」スキル版を参考）

参考: [kociden/sakurai-skill](https://github.com/kociden/sakurai-skill)（YouTube「桜井政博のゲーム作るには」の字幕から作られた非公式スキル）。

- **リスクとリターン**: 写真は寄る・真横から・中央・クリアなほど高評価（S/A/B/C）。ただし体がフレームからはみ出すとS評価にならず大きく減点（見切れ減点）、画面いっぱいに寄りすぎても減点。危険な相手（旋回・突進中のサメ、縄張りのゴマモンガラ）やダウンカレント中、深場の撮影には手当が付く。照準に評価がリアルタイムで出るので、どう撮れば上がるかがその場で分かる。
- **ご褒美は使い道とセット・目の前に吊るす**: 写真は雑誌に売れて円になる。装備は**図鑑の達成率で入荷し、そのうえで円で買う**二段構え。タイトルとリザルトに「○○入荷まで図鑑あと○種／あと¥○」を常に表示。
- **装備（11種）**: ロングフィン／強力ライト（暗所で遠くまで撮れる）／ドライスーツ（流氷の入り江でエアが3倍減らない）／大型タンク／マクロレンズ（20cm未満を大きく写せる）／リブリーザー（泡が出ず魚の逃げる距離が半分、縄張り魚にも気づかれにくい）／ワイドレンズ（1m以上の大物を遠くから撮れる）／シャークシールド（突進を寸前で追い払う）／水中スクーター／魚群探知機（近くの未撮影の生き物をマップに表示）／大気圧潜水服。
- **流氷の入り江**: 西の新エリア（水温2℃）。流氷・コンブの森・岩場に、ダンゴウオやクリオネ、ミズダコ、タラバガニなど18種。ドライスーツなしでも潜れるが、エアの減りが3倍になる。
- **ほめる**: 撮影時に評価スタンプとヒットストップ、リザルトで売上のカウントアップ。
- **罰は行いに見合う大きさに**: エア切れで気絶しても図鑑の記録は失わず、救助費用として売上が30%になる。
- **最初にクライマックス**: 初回ダイブはエントリー直後にウミガメが現れる。
- 調整値は `src/game/photoScore.ts` の `PHOTO` / `SHOP` にまとめている。
- **しおさい亭（陸の食堂）と銛漁**: 女将が腰を痛めた港町の食堂を手伝う、という陸のストーリー。ロジックは `src/game/fishing.ts`（調整値は `FISHING`）、画面は `src/game/kitchen.ts`。
  - 潜水中に銛ボタン（G/Tキー）でカメラと銛を持ち替える。照準に命中率・重さ・獲れない理由（届かない／小さすぎる／毒／保護種／クーラーに入らない／手銛では重すぎる）が出る。外すと魚は逃げ、獲ると血の匂いで近くのサメが寄ってくることがある。気絶すると獲物は流される。
  - 手銛（射程2.2m・8kgまで）→ 漁業権＋水中銃（射程6m・大物OK）。持ち帰れる重さは網袋5kg → クーラー15kg → 大型クーラー40kg。漁具は食堂の評判レベルで入荷し、お金で買う。
  - 食堂では、お客さんの注文（白身の煮付け・青魚の刺身・特定の魚・宴会の鍋など）に合う魚を出してお金と評判を得る。自分で食べる「まかない」は次のダイブに効く（煮付け＝寒さに強い、刺身＝エア長持ち、塩焼き＝泳ぎが速い、唐揚げ＝銛が当たる、鍋＝エア容量UP）。余った魚は市場へ。
  - 評判Lv1〜6でストーリーが進み、注文・漁具・昼夜の選択が解放される。
- **昼と夜**: 1日の潜水時間が約10分を超えると日が傾き、約13分で夜の海になる（潜水中にそのまま暗くなり、夜行性の生き物が出てくる）。食堂で休むと翌朝。評判Lv3になるとボートで昼・夜を選べる。
- **潜水中の依頼（ミニゲーム）**: 1ダイブに最大2回、潜って40秒以降に時々「依頼が来た！」と提案される（`src/game/missions.ts` の `MISSION`）。内容・制限時間・報酬を見て「受ける」を押したときだけ始まり、「断る」か15秒放置で消える。失敗してもペナルティなし。
  - ウニ駆除（岩礁・流氷の入り江）: 75秒でウニ10個。近づくと拾える
  - 海のごみ拾い（ラグーン・サンゴ礁）: 80秒でごみ6個
  - 雑誌の撮影依頼（全域）: 近くにいる生き物を90秒以内にB評価以上で撮る
  - 落とし物のカメラ探し（サンゴ礁・ドロップオフ）: マップのおおよその印と「近い／遠い」のヒントで探す
- **海の哺乳類・ペンギン・伝説の古生物**: シャチ・マッコウクジラ（沖・深海）、トド・ゴマフアザラシ・キタオットセイ・ラッコ（流氷の入り江、好奇心が強く寄ってくる種も）、コウテイペンギン・イワトビペンギン（本来は南半球の鳥だが入り江に出る）。レア度★4「伝説」の古生物（出現率7%）: シーラカンス、ダンクルオステウス・メガロドン（突進してくる個体あり）、フタバスズキリュウ、アンモナイト、アノマロカリス、三葉虫。流氷の入り江の魚・カニ・エビも追加。さらにスズメダイ・ハゼ・ウミウシ・甲殻類・頭足類・イルカなど148種を加えて全600種。
- **新マップ（西側・東側）**:
  - 海底遺跡・沈船の墓場: 与那国の海底地形のような石の段々、柱や門、崩れた石塊、3隻の沈没船。宝探しの依頼が出る
  - ブルーホール: 水深7mの白砂に開いた深さ55mの縦穴。壁の28〜44mに鍾乳石。オウムガイ、オオメジロザメなど
  - 水中洞窟（セノーテ）: 縦穴から天井付きの通路へ。天井の下は日光が届かず暗い（ライトがないと撮れない）。黄色いガイドロープ、奥の大広間にムカデエビ
  - 海藻の森（東側）: 水面まで伸びるジャイアントケルプの森（カリフォルニア沖がモデル）。ガリバルディ、シープヘッド、タツノオトシゴ、カリフォルニアアシカなど。ウニ駆除の依頼も出る
- **ナイトダイブ**: タイトルで切り替え。全ポイントで夜に潜れる。暗く、ライトで照らさないと撮れない。泳ぐと夜光虫が光る。夜だけ出る生き物（ウミホタル、ゾウリエビ、ハナイカ、寝袋で眠るブダイ）と夜間手当×1.3。
