# BLUE DEPTHS

スマホブラウザ向けの3Dダイビング＆写真図鑑ゲーム（Three.js / TypeScript / Vite）。
浅瀬ラグーン・サンゴ礁・岩礁・ドロップオフ／沖・深海をはじめ海藻の森・洞窟・ブルーホール・遺跡など多数のエリアで、613種の生き物（魚＋ナマコ・ヒトデ・ウニ・シャコガイ・イバラカンザシ・ウミシダ・エビ・ヤドカリ・ウミヘビ・ウミウシ・クラゲ・クシクラゲ・ヒカリボヤ・ウミユリなど）を撮影して図鑑を埋める。
モデル・テクスチャ・音はすべて手続き生成（外部API・有料素材なし）。設計は `DESIGN.md`。

- 浅場の魚の種類と配色は quiz リポジトリの `images/`（沖縄の浅海魚の写真）を参考に作成（写真そのものは使っていない）。
- 砂地・サンゴ礫・礁の基盤・岩・沈没船の錆は Poly Haven の CC0 実写PBRテクスチャ（`scripts/prep_pbr.py` で整形、出典は `src/assets/tex/CREDITS.md`）。サンゴのポリプ・ノウサンゴの模様は `scripts/gen_textures.py`（numpy）で焼いた法線＋アルベドのタイル画像を、トライプラナーで貼っている。
- 大型〜中型の魚31種（ジンベエザメ・サメ類・メガネモチノウオ・カジキ・アジ類・ハタ・ベラ・タイなど）は、Wikimedia Commons の**パブリックドメイン／CC0**の写真・博物画を `scripts/photo_fish.py`（rembg IS-Net で切り抜き→色補正→シルエット抽出）で加工し、写真の輪郭から胴の厚みを推定したメッシュに貼っている。出典は `src/assets/fish/CREDITS.md`、採用写真と処理設定は `scripts/photo_fish_picks.json`。
- 魚は生態ごとの「くらし（マイクロハビタット）」を持つ：枝サンゴの上に浮かぶ／サンゴをついばむ／テーブルサンゴの下に潜む／サンゴや岩の上にとまる／砂地の巣穴でホバリング／砂地すれすれで採餌／礁縁の中層で群れる／壁沿い／水面直下／海草藻場／クリーニングステーション など。

## 遊び方
| 操作 | スマホ | PC |
| --- | --- | --- |
| 泳ぐ（視線方向） | 画面左側をドラッグ | WASD |
| 見回す | 画面右側をドラッグ | マウスドラッグ |
| 浮上／潜降 | ▲▼ボタン | Space / Shift |
| 撮影 | カメラボタン | E |
| ライト | ライトボタン | L |
| 図鑑 | 右上の図鑑 | M |
| マップ | 左上の丸いミニマップをタップ | N |

- エアは深いほど速く減る。エア切れや窒素酔いで気絶すると救助され、売上は救助費用で減る（図鑑の記録は残る）。浮上すると図鑑に登録。
- **エアの警告は1ダイブに2回だけ**（修正バッチ2 F1）: 残りが35%を切ったときと、本当にぎりぎり（20bar未満か残り約30秒）のとき。ゲージの色が変わるだけで点滅はしない。
- **スティックの前後は水平に進む**（修正バッチ2 F2）: 原則「操作は思ったとおりに動く」→ 問題：潜水開始時はカメラが約20°下を向いていて、スティックを前に倒すだけで斜めに沈んだ → スティックの前後は水平に進み、上下は▲▼ボタンだけ。真上・真下に近い向き（視線の傾き 50°〜70° で 0→全量）を見ているときだけ、見ている方向へ縦にも進む（穴やドロップオフを覗いて降りられる）。
- **サンゴやウニを地面に着ける**（F2）: 原則「見た目の違和感は没入を壊す」→ 問題：置き物の中心 1 点の高さに底を合わせていて、斜面で片側が浮いて見えた → 足元の 5 点（中心＋四隅）の最も低い高さに合わせ、斜面は傾き×半径の分だけ埋める（`flora.ts` の `PLACE`）。ウニは足元の岩・サンゴ上面の最小値へ。計測は `scripts/probe-float.cjs`（地形は変えない）。
- **ボートの錨**（F2）: 潜るとボートの船首から錨綱が海底まで伸び、海底に錨がある（`world/anchor.ts`）。ボートは穏やかに揺れ、綱の上端だけがそれに合わせて動く。
- **窒素酔い**: 約55mより深い所に居続けると60秒で気絶する（2段目では水深の数字が乱れる）。浅い所へ戻ると回復する。
- **設定**（ボート画面の歯車、潜水中は一時停止の「設定」）: シャッターと移動ボタン（▲▼・ライト・銛・餌）の大きさを70〜130%で変えられる（100% は実機で確認したちょうどよい大きさ）。この端末に保存され、進行度をリセットしても残る。
- 写真の評価は S 70点〜・A 55点〜・B 40点〜。図鑑に飛んだあと「閉じる」で潜水（結果画面）に戻る。図鑑の一覧から開いたときは一覧に戻る。
- 同じ種の写真が売れるのは**1回のダイブで1枚（最初の1枚）だけ**。2枚目以降は図鑑の記録写真（自己ベスト）だけ更新される（発見カードに「売上済み（1ダイブ1種1回）」）。潜り直せばまた売れる。このルールはチュートリアルで説明する。
- **はじまり**: 新しく始めると、ボート画面を経ずに浅瀬ラグーンの海の中から始まる。主人公は趣味で海の写真を撮ってきたダイバーで、その写真が『月刊うみなか』の編集長の目に留まって島に呼ばれた（プロローグ）。最初のダイブは試し撮り＝チュートリアル。浮上すると編集長に褒められ、正式に仕事（章ごとの課題と報酬）を頼まれる。
- **時間**: 浮上すると夜になる。**夜に始めた潜水の後は、結果画面を閉じると自動で翌朝**（日付 +1・クーラーの残りは市場へ。夜明けの演出が入る。食堂のウニ漁は時間を変えない）。泊まっている港の食堂「しおさい亭」で「朝にする（寝る）」を押しても翌朝（同じ処理と演出）。水中ライトを持っていれば、同じボタンが朝〜夕方は「夜にする」に変わる。しおさい亭では女将のハルさんが朝や帰ったときに一言くれて、島のこと（世界中の魚が集まる、寒い海もある、海底の言い伝え…）を少しずつ話してくれる。2日目の朝に「依頼の掲示板」を教えてくれる。
- **夜明けの演出**（修正バッチ2 F7 (10)(26)）: 寝たとき・夜に潜った後は、0.6 秒で暗転 → 中央に「◯日目の朝」と天気のアイコンを 1.2 秒 → 明けてボート画面へ（しおさい亭にいたら閉じる）。タップで早送り。女将さんの朝のひとこと（天気、残りの魚を市場に卸した金額）はボート画面の吹き出しで 1 段だけ（タップで閉じる）。原則「やった後のごほうび・場面の切り替えは見せる」→ 問題：寝ても夜が明けた実感がなく、夜の潜水の後に自分で寝直す手間があった → 夜の潜水の後は自動で朝にして演出を入れた（`src/ui/transit.ts` の `Dawn`、数値は `DAWN`）。
- **ボートで向かう演出**（F7 (17)(29)）: ダイブポイントを押すと、海図の上をボートが走る 2D の演出（1.2〜2.0 秒、行き先までの距離で決まる。ウニ漁は店の前から岩礁へ 1.0 秒）。航跡を引いて進み、行き先の名前と水深が出て、暗転して潜水へ。エンジン音と波の音は Web Audio で合成（`audio.ts` の `travel`）。タップで飛ばせる。潜水の準備（生き物の生成・シェーダの事前コンパイル）はこの演出の裏で進める。ボートは潜った地点に浮かんだままで、朝になると港に戻る（次の演出の出発点）。数値は `TRAVEL`、描画は `Minimap.drawRoute`。
- **夜の海**はライトがないと潜れない（水中ライトは図鑑20種でショップに入荷する。強力ライトを持っていれば不要）。夜はしおさい亭で寝れば翌朝。夜は昼の魚が眠って少なく、夜だけの生き物（ゴシキエビ・ウチワエビ・ヒメイカ・ベニテンジクダイなど）が出る。浅場ではオキザヨリがライトめがけて突進してくる（ライトを消せば外れる）。
- 潜水中に日が暮れても潜り続けられるが、ライトがないと暗くて撮りにくい。
- ウミガメの救出に成功すると、そのダイブの間ウミガメがついてきて一緒に泳ぐ。見つかったときは漁師のゲンさんが［助ける］［今はやめる］を聞いてくる（やめたらそのダイブでは再び出ない）。初めて助けるときだけ、操作の説明が小型吹き出しで出る。
- 図鑑5/12/22/35種でフィン・大型タンク・水中スクーター・大気圧潜水服（深海解放）を入手。

## マップ：河口と川（Phase 9）
世界の南（ラグーンの奥の陸地）に、泳いで入れる 2 つのマップがある。ボート画面の行き先に「河口」「川」が並ぶ（泳いで入ると発見）。
- **河口**（汽水域）：マングローブの根の迷路・干潟・流木・沈んだ舟・ヨシ。水は茶緑で視程 16m。アカメ（ヌシ）・マハゼ・トビハゼ・シオマネキなど 18 種。
- **川**：下流の淵 → 中流の瀬 → 滝つぼ（上流の端は落差 6m の滝）。水は下流が緑で上流ほど青緑、視程は下流 18m → 上流 34m。流れは下流向きで瀬が速く、逆らって泳ぐ間だけエアが多く減る（最大 1.4 倍）。コイ・アユ・ヤマメ・イワナ・オオサンショウウオ（ヌシ）など 24 種。
- **川では銛を使えない**（ボタンが隠れる）。アカメとオオサンショウウオは保護で、持ち帰ると没収・罰金・評判減。
- 写真スポット（マングローブの根の迷路・滝つぼの光の泡）、宝箱、特別な光景（闇に光る赤い目・瀬を上るアユの群れ）、依頼・掲示板にも対応。設計は `docs/PHASE9-DESIGN.md`、検証は `scripts/probe-phase9.cjs`。

## 描画の軽さ
描く画素数は 90 万までで、重い端末では自動で下げる。影・サンゴの細かさ・小物・生き物の更新は距離で切り替える（調整値は `src/game/render.ts`）。URL の末尾に `?diag`、またはデバッグ欄で fps などの診断表示を出せる。検証は `scripts/probe-phase8.cjs`。

## 魚の形と泳ぎ
魚は種ごとに手続きで作る（`src/life/models.ts` の `buildFish`）。断面はスーパー楕円、横幅は高さと別の包絡線で、尾柄が細い。ヒレは格子で作り、尾びれ・背びれ・胸びれが泳ぎに合わせて滑らかに曲がる。泳ぎは頂点シェーダで背骨の線に沿って曲げ、尾の振りの速さは個体の泳ぐ速さで変わる（ウナギ型・標準・アジ型・マグロ型・胸びれ型。`src/life/swim.ts`）。体型テンプレート（`src/life/species2.ts` の `B`）に断面のかど `xs`・口の位置 `mouth`・鱗の列数 `scaleN`・泳ぎ方 `swimMode` などがある。海の哺乳類・ペンギン・ウミヘビは今までの形と動き。

## 撮影の判定
写真として認められるのは次の条件をすべて満たしたときだけ：写真の切り出し範囲に入っている／画面の6%以上の大きさで写っている／水の濁りで霞まない距離（視程から計算）／地形に隠れていない／深海ではライトの照射範囲内か自ら発光している。

## ゲーム性の設計メモ（「桜井政博のゲーム作るには」スキル版を参考）

- **画面は情報の取捨選択（修正バッチ2 F1）**: 原則「海の中が主役。触る物は親指で押せる大きさ、常時出る情報は小さく」→ 問題：Phase 7 で拡大した HUD が大きすぎ（シャッター118・ボタン70・水深44・チュートリアル18px）、角度と最大水深は使い道がなかった。→ 一段小さく（96／58／34／15px、触る物は最小44px）、シャッターと移動ボタンは設定で70〜130%に（CSS変数 `--shutter-k`・`--ctl-k`、セーブ `ui`）。角度・最大水深の行と一時停止の「図鑑を見る」・宝箱の上の四角（点の描画が正方形に見えていた）を削除。エアの数字は flex で円の中心に。
- **警告は大事なときに一度だけ（修正バッチ2 F1）**: 原則「プレイヤーを疲れさせる通知を出し続けない」→ 問題：エアが50bar未満の間、点滅と警告が止まらなかった。→ 半分を切ったとき（35%）と本当にぎりぎり（20bar未満か残り30秒）の2回だけ（`AIR_WARN`）。窒素酔いは気絶まで10秒→60秒（`NARCOSIS.blackoutSec`）で、残り20秒から強い警告。
- **写真から来たら写真の場所へ戻す（修正バッチ2 F1）**: 問題：発見カードから図鑑の詳細を開き、閉じると図鑑の一覧が残って、さらに閉じないと潜水に戻れなかった。→ `dexDirect` で、写真から直接来たときは詳細を閉じたら潜水（結果画面）へ戻す。一覧から開いたときは従来どおり。
- **S 評価を取りやすく（修正バッチ2 F1）**: 問題：S が難しすぎる。→ S の下限を86→70（今のA）、A 55・B 40（倍率は据え置き）。稼ぎの増え方は F13 で確認。
- **掲示板は5日目から（修正バッチ2 F1）**: 最初の日々はまず潜ることに集中させる（`BOARD_DAY = 5`。すでに掲示板が出ているセーブはそのまま）。

参考: [kociden/sakurai-skill](https://github.com/kociden/sakurai-skill)（YouTube「桜井政博のゲーム作るには」の字幕から作られた非公式スキル）。

- **リスクとリターン**: 写真は寄る・真横から・中央・クリアなほど高評価（S/A/B/C）。ただし体がフレームからはみ出すとS評価にならず大きく減点（見切れ減点）、画面いっぱいに寄りすぎても減点。危険な相手（旋回・突進中のサメ、縄張りのゴマモンガラ）やダウンカレント中、深場の撮影には手当が付く。照準に評価がリアルタイムで出るので、どう撮れば上がるかがその場で分かる。
- **ご褒美は使い道とセット・目の前に吊るす**: 写真は雑誌に売れて円になる。装備は**図鑑の種数（絶対数）で入荷し、そのうえで円で買う**二段構え。タイトルとリザルトに「「？」入荷まで図鑑あと○種／「○○」まであと¥○」を常に表示（未入荷の商品名は出さない）。
- **装備（11種）**: ロングフィン／水中ライト（図鑑20種）とその強化の強力ライト（図鑑70種・暗所で遠くまで撮れる。別の商品ではなく水中ライトの枠の中の「強化」）／ドライスーツ（流氷の入り江でエアが3倍減らない）／大型タンク／マクロレンズ（20cm未満を大きく写せる）／リブリーザー（泡が出ず魚の逃げる距離が半分、縄張り魚にも気づかれにくい）／ワイドレンズ（1m以上の大物を遠くから撮れる）／シャークシールド（突進を寸前で追い払う）／水中スクーター／魚群探知機（近くの未撮影の生き物をマップに表示）／大気圧潜水服。
- **流氷の入り江**: 西の新エリア（水温2℃）。流氷・コンブの森・岩場に、ダンゴウオやクリオネ、ミズダコ、タラバガニなど18種。ドライスーツなしでも潜れるが、エアの減りが3倍になる。
- **ほめる**: 撮影時に評価スタンプとヒットストップ、リザルトで売上のカウントアップ。
- **罰は行いに見合う大きさに**: エア切れで気絶しても図鑑の記録は失わず、救助費用として売上が30%になる。
- **最初にクライマックス**: 初回ダイブはエントリー直後にウミガメが現れる。
- 調整値は `src/game/photoScore.ts` の `PHOTO` / `SHOP` にまとめている。
- **探す楽しさを残す／画面の主役をふさがない**: 依頼の場所がマップの「点」だと、そこへ一直線に泳ぐだけで探す遊びにならなかった。また残り時間のパネルが照準のすぐ上にあり、撮りたい生き物にかぶっていた。→ 依頼は「この円の中のどこか」を示す金色の破線の円にし（目的物は円の中心からずらす、`missions.ts` の `MISSION.area`）、パネルは画面の上端へ小さくまとめた。
- **目的とストーリー**（`src/game/story.ts`）: 駆け出しの海中写真家が、海洋雑誌『月刊うみなか』の表紙を目指す。全7章、各章に1つの目標（図鑑15種、S評価、夜の魚、特別な光景、★3をS評価…）。クリアで報酬・写真家の評価がもらえる。
  - **特別な光景（実績）**（定義は `story.ts` の `SCENES`、演出は `src/game/scenes.ts`）: 全11種。縦になって眠るマッコウクジラ、サンゴの一斉産卵、イワシのベイトボール、マンタトレイン、立ち泳ぎで食事するジンベエザメ、ザトウクジラの親子、イルカと泳ぐ、ハンマーヘッドの群れ、夜光虫の青い光、シャチの家族、ギンガメアジのトルネード。ダイブポイントと昼夜ごとに確率で1ダイブ1つまで起こり、近づくと「何かの気配」が知らされる。撮ると実績解除。ボートのアルバムに写真と、未発見のものは出会える場所のヒントが並ぶ。マッコウクジラとサンゴの産卵はストーリーの章で一度必ず起こり、その後は確率で出会える。**円は最初から出ない**（修正バッチ2 F8）：章の光景は潜り始めに編集長が場所の手がかりを言い、近づいて「気配」が出てから金色の円が出る。主役（個体・粒子）が画面内・25m 以内に入った瞬間に、上部に金色の縁の帯「特別な光景 ◯◯」が 3 秒＋チャイム＋編集長のひとこと（初回の光景だけ「これはすごい…！ 撮影しよう」）。アルバムの「？？？」のヒント文には「出会えるかは運しだい」。
  - **チュートリアル**: 最初のダイブ（試し撮り）で、泳ぐ→見回す→▼で潜る→撮影→写真はお金になる・3種撮る→2枚目以降のルール→エアの見方→浮上、の8ステップを1つずつ実際にやって覚える（できた瞬間にほめる、チュートリアル中はエアの減りが半分、飛ばせる）。表示は画面上端（縦画面はミニマップの下）で、中央の照準にかからない。
