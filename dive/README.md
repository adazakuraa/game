# BLUE DEPTHS

スマホブラウザ向けの3Dダイビング＆写真図鑑ゲーム（Three.js / TypeScript / Vite）。
浅瀬ラグーン・サンゴ礁・岩礁・ドロップオフ／沖・深海をはじめ海藻の森・洞窟・ブルーホール・遺跡など多数のエリアで、613種の生き物（魚＋ナマコ・ヒトデ・ウニ・シャコガイ・イバラカンザシ・ウミシダ・エビ・ヤドカリ・ウミヘビ・ウミウシ・クラゲ・クシクラゲ・ヒカリボヤ・ウミユリなど）を撮影して図鑑を埋める。
モデル・テクスチャ・音はすべて手続き生成（外部API・有料素材なし）。設計は `DESIGN.md`。

- 浅場の魚の種類と配色は quiz リポジトリの `images/`（沖縄の浅海魚の写真）を参考に作成（写真そのものは使っていない）。
- 砂地・サンゴ礫・礁の基盤・岩・沈没船の錆は Poly Haven の CC0 実写PBRテクスチャ（`scripts/prep_pbr.py` で整形、出典は `src/assets/tex/CREDITS.md`）。サンゴのポリプ・ノウサンゴの模様は `scripts/gen_textures.py`（numpy）で焼いた法線＋アルベドのタイル画像を、トライプラナーで貼っている。
- 大型〜中型の魚31種（ジンベエザメ・サメ類・メガネモチノウオ・カジキ・アジ類・ハタ・ベラ・タイなど）は、Wikimedia Commons の**パブリックドメイン／CC0**の写真・博物画を `scripts/photo_fish.py`（rembg IS-Net で切り抜き→色補正→シルエット抽出）で加工し、写真の輪郭から胴の厚みを推定したメッシュに貼っている。出典は `src/assets/fish/CREDITS.md`、採用写真と処理設定は `scripts/photo_fish_picks.json`。
- 魚は生態ごとの「くらし（マイクロハビタット）」を持つ：枝サンゴの上に浮かぶ／サンゴをついばむ／テーブルサンゴの下に潜む／サンゴや岩の上にとまる／砂地の巣穴でホバリング／砂地すれすれで採餌／礁縁の中層で群れる／壁沿い／水面直下／海草藻場／クリーニングステーション など。

## 遊び方
| 操作 | スマホ | PC |
| --- | --- | --- |
| 泳ぐ（視線方向） | 画面左側をドラッグ | WASD |
| 見回す | 画面右側をドラッグ | マウスドラッグ |
| 浮上／潜降 | ▲▼ボタン | Space / Shift |
| 撮影 | カメラボタン | E |
| ライト | ライトボタン | L |
| 図鑑 | 右上の図鑑 | M |
| マップ | 左上の丸いミニマップをタップ | N |

- エアは深いほど速く減る。エア切れや窒素酔いで気絶すると救助され、売上は救助費用で減る（図鑑の記録は残る）。浮上すると図鑑に登録。
- 同じ種の写真が売れるのは**1回のダイブで1枚（最初の1枚）だけ**。2枚目以降は図鑑の記録写真（自己ベスト）だけ更新される（発見カードに「売上済み（1ダイブ1種1回）」）。潜り直せばまた売れる。このルールはチュートリアルで説明する。
- **はじまり**: 新しく始めると、ボート画面を経ずに浅瀬ラグーンの海の中から始まる。主人公は趣味で海の写真を撮ってきたダイバーで、その写真が『月刊うみなか』の編集長の目に留まって島に呼ばれた（プロローグ）。最初のダイブは試し撮り＝チュートリアル。浮上すると編集長に褒められ、正式に仕事（章ごとの課題と報酬）を頼まれる。
- **時間**: 浮上すると夜になる。泊まっている港の食堂「しおさい亭」で「朝にする（寝る）」を押すと翌朝。水中ライトを持っていれば、同じボタンが朝〜夕方は「夜にする」に変わる。しおさい亭では女将のハルさんが朝や帰ったときに一言くれて、島のこと（世界中の魚が集まる、寒い海もある、海底の言い伝え…）を少しずつ話してくれる。2日目の朝に「依頼の掲示板」を教えてくれる。
- **夜の海**はライトがないと潜れない（ライトは図鑑45種でショップに入荷する。強力ライトを持っていれば不要）。夜はしおさい亭で寝れば翌朝。夜は昼の魚が眠って少なく、夜だけの生き物（ゴシキエビ・ウチワエビ・ヒメイカ・ベニテンジクダイなど）が出る。浅場ではオキザヨリがライトめがけて突進してくる（ライトを消せば外れる）。
- 潜水中に日が暮れても潜り続けられるが、ライトがないと暗くて撮りにくい。
- ウミガメの救出に成功すると、そのダイブの間ウミガメがついてきて一緒に泳ぐ。
- 図鑑5/12/22/35種でフィン・大型タンク・水中スクーター・大気圧潜水服（深海解放）を入手。

## マップ：河口と川（Phase 9）
世界の南（ラグーンの奥の陸地）に、泳いで入れる 2 つのマップがある。ボート画面の行き先に「河口」「川」が並ぶ（泳いで入ると発見）。
- **河口**（汽水域）：マングローブの根の迷路・干潟・流木・沈んだ舟・ヨシ。水は茶緑で視程 16m。アカメ（ヌシ）・マハゼ・トビハゼ・シオマネキなど 18 種。
- **川**：下流の淵 → 中流の瀬 → 滝つぼ（上流の端は落差 6m の滝）。水は下流が緑で上流ほど青緑、視程は下流 18m → 上流 34m。流れは下流向きで瀬が速く、逆らって泳ぐ間だけエアが多く減る（最大 1.4 倍）。コイ・アユ・ヤマメ・イワナ・オオサンショウウオ（ヌシ）など 24 種。
- **川では銛を使えない**（ボタンが隠れる）。アカメとオオサンショウウオは保護で、持ち帰ると没収・罰金・評判減。
- 写真スポット（マングローブの根の迷路・滝つぼの光の泡）、宝箱、特別な光景（闇に光る赤い目・瀬を上るアユの群れ）、依頼・掲示板にも対応。設計は `docs/PHASE9-DESIGN.md`、検証は `scripts/probe-phase9.cjs`。

## 描画の軽さ
描く画素数は 90 万までで、重い端末では自動で下げる。影・サンゴの細かさ・小物・生き物の更新は距離で切り替える（調整値は `src/game/render.ts`）。URL の末尾に `?diag`、またはデバッグ欄で fps などの診断表示を出せる。検証は `scripts/probe-phase8.cjs`。

## 魚の形と泳ぎ
魚は種ごとに手続きで作る（`src/life/models.ts` の `buildFish`）。断面はスーパー楕円、横幅は高さと別の包絡線で、尾柄が細い。ヒレは格子で作り、尾びれ・背びれ・胸びれが泳ぎに合わせて滑らかに曲がる。泳ぎは頂点シェーダで背骨の線に沿って曲げ、尾の振りの速さは個体の泳ぐ速さで変わる（ウナギ型・標準・アジ型・マグロ型・胸びれ型。`src/life/swim.ts`）。体型テンプレート（`src/life/species2.ts` の `B`）に断面のかど `xs`・口の位置 `mouth`・鱗の列数 `scaleN`・泳ぎ方 `swimMode` などがある。海の哺乳類・ペンギン・ウミヘビは今までの形と動き。

## 撮影の判定
写真として認められるのは次の条件をすべて満たしたときだけ：写真の切り出し範囲に入っている／画面の6%以上の大きさで写っている／水の濁りで霞まない距離（視程から計算）／地形に隠れていない／深海ではライトの照射範囲内か自ら発光している。

## ゲーム性の設計メモ（「桜井政博のゲーム作るには」スキル版を参考）

参考: [kociden/sakurai-skill](https://github.com/kociden/sakurai-skill)（YouTube「桜井政博のゲーム作るには」の字幕から作られた非公式スキル）。

- **リスクとリターン**: 写真は寄る・真横から・中央・クリアなほど高評価（S/A/B/C）。ただし体がフレームからはみ出すとS評価にならず大きく減点（見切れ減点）、画面いっぱいに寄りすぎても減点。危険な相手（旋回・突進中のサメ、縄張りのゴマモンガラ）やダウンカレント中、深場の撮影には手当が付く。照準に評価がリアルタイムで出るので、どう撮れば上がるかがその場で分かる。
- **ご褒美は使い道とセット・目の前に吊るす**: 写真は雑誌に売れて円になる。装備は**図鑑の種数（絶対数）で入荷し、そのうえで円で買う**二段構え。タイトルとリザルトに「「？」入荷まで図鑑あと○種／「○○」まであと¥○」を常に表示（未入荷の商品名は出さない）。
- **装備（11種）**: ロングフィン／強力ライト（暗所で遠くまで撮れる）／ドライスーツ（流氷の入り江でエアが3倍減らない）／大型タンク／マクロレンズ（20cm未満を大きく写せる）／リブリーザー（泡が出ず魚の逃げる距離が半分、縄張り魚にも気づかれにくい）／ワイドレンズ（1m以上の大物を遠くから撮れる）／シャークシールド（突進を寸前で追い払う）／水中スクーター／魚群探知機（近くの未撮影の生き物をマップに表示）／大気圧潜水服。
- **流氷の入り江**: 西の新エリア（水温2℃）。流氷・コンブの森・岩場に、ダンゴウオやクリオネ、ミズダコ、タラバガニなど18種。ドライスーツなしでも潜れるが、エアの減りが3倍になる。
- **ほめる**: 撮影時に評価スタンプとヒットストップ、リザルトで売上のカウントアップ。
- **罰は行いに見合う大きさに**: エア切れで気絶しても図鑑の記録は失わず、救助費用として売上が30%になる。
- **最初にクライマックス**: 初回ダイブはエントリー直後にウミガメが現れる。
- 調整値は `src/game/photoScore.ts` の `PHOTO` / `SHOP` にまとめている。
- **探す楽しさを残す／画面の主役をふさがない**: 依頼の場所がマップの「点」だと、そこへ一直線に泳ぐだけで探す遊びにならなかった。また残り時間のパネルが照準のすぐ上にあり、撮りたい生き物にかぶっていた。→ 依頼は「この円の中のどこか」を示す金色の破線の円にし（目的物は円の中心からずらす、`missions.ts` の `MISSION.area`）、パネルは画面の上端へ小さくまとめた。
- **目的とストーリー**（`src/game/story.ts`）: 駆け出しの海中写真家が、海洋雑誌『月刊うみなか』の表紙を目指す。全7章、各章に1つの目標（図鑑15種、S評価、夜の魚、特別な光景、★3をS評価…）。クリアで報酬・写真家の評価・海図がもらえる。
  - **特別な光景（実績）**（定義は `story.ts` の `SCENES`、演出は `src/game/scenes.ts`）: 全11種。縦になって眠るマッコウクジラ、サンゴの一斉産卵、イワシのベイトボール、マンタトレイン、立ち泳ぎで食事するジンベエザメ、ザトウクジラの親子、イルカと泳ぐ、ハンマーヘッドの群れ、夜光虫の青い光、シャチの家族、ギンガメアジのトルネード。ダイブポイントと昼夜ごとに確率で1ダイブ1つまで起こり、近づくと「何かの気配」が知らされる。撮ると実績解除。ボートのアルバムに写真と、未発見のものは出会える場所のヒントが並ぶ。マッコウクジラとサンゴの産卵はストーリーの章で一度必ず起こり（地図に金色の円）、その後は確率で出会える。
  - **チュートリアル**: 最初のダイブ（試し撮り）で、泳ぐ→見回す→▼で潜る→撮影→写真はお金になる・3種撮る→2枚目以降のルール→エアの見方→浮上、の8ステップを1つずつ実際にやって覚える（できた瞬間にほめる、チュートリアル中はエアの減りが半分、飛ばせる）。表示は画面上端（縦画面はミニマップの下）で、中央の照準にかからない。
- **エアタンクの強化**: タンクは買い替えずに1本を段階的に強化する（`photoScore.ts` の `AIR_TANK`）。最初は105barから、140・170・210・260・320・400barへ。潜水中のエアはリングと bar の数値だけで示し、残り時間は出さない。手銛を手に入れた後は、お金の半額＋クーラーの魚（kg）でも強化できる。
- **写真で稼げすぎる（Phase 2）**: 原則「ご褒美は使い道とセット」→ 問題：写真の売上だけで装備がすぐ揃い、依頼や章の報酬の意味が薄かった → 写真の基本報酬を約1/7（★1〜★4 = ¥40/130/340/1,140）にし、特別な光景の報酬も同じく1/7。依頼・食堂・章の報酬は据え置きで、主な稼ぎ先になる。
- **装備の解放は種数で（Phase 2）**: 原則「やり込みは強制しない」→ 問題：入荷が図鑑の割合（%）だったので、生き物を追加するたびに入荷が遠のいた。水中ライト・手銛が序盤すぎた → 入荷条件を図鑑の種数（ロングフィン10・ドライスーツ25・シグナルフロート30・水中ライト45・強力ライト55・手銛60…大気圧潜水服150）にした。図鑑600種以上を埋めるのはやり込み。旧セーブで入荷済みだった商品は入荷済みのまま（セーブの `stocked`）。
- **浮上の制限（Phase 2）**: 原則「リスクとリターン」→ 問題：一時停止メニューからどこでも浮上でき、エア管理の緊張がなかった → 一時停止からは浮上できず、水面近く（1.6mより浅く）まで上がって浮上する。ショップの「シグナルフロート」を買うと、どこからでも浮上できる（一時停止メニューと浮上ボタン）。
- **ショップの表示（Phase 2）**: 買える商品は点滅させず、明るい緑の地で示す。未入荷の商品はアイコンも名前も「？」。
- **編集長の報酬は自分で受け取る（Phase 3）**: 原則「ご褒美はプレイヤーに見せる」→ 問題：章をクリアすると報酬が黙って所持金に足され、もらえていないように見えた → クリアすると結果画面に「ボートで報酬を受け取ろう」、ボートの章カードに「報酬 ¥◯ を受け取る」ボタンが出る。押すとお金が増える音と表示。受け取らなくても失効せず、章の進行も止まらない（セーブの `storyClaim`）。
- **Sのコツを教える（Phase 3）**: 原則「上達の手がかりを見せる」→ 問題：Sの条件が分からなかった → S評価が必要な章（第3章・第7章）の章カードに編集長の「Sを取るコツ」（近づいて大きく・真横から・真ん中に・全身を枠に・近いほどくっきり）。その章の間は、Sでなかった写真のいちばん足りない点を撮った直後に一言で教える（`photoScore.ts` の `sAdvice`）。第4章の目標は「夜の魚を撮る」（夜の魚の仲間だけを数える）。
- **掲示板の依頼は消えない（Phase 3）**: 「やめる」と依頼は掲示板に元のまま戻る。掲示板は「掲示板＋受けている依頼」で3枠。受けても補充されず、1つ達成すると新しい依頼が1つ貼り出される（NEW の印）。手銛があれば、掲示板の下にしおさい亭の注文の件数と「しおさい亭へ」も出る。
- **海中のハプニングを控えめに（Phase 3）**: ウミガメの網は潜水60秒後から10秒ごと5%、出たダイブの次のダイブでは出ない（3分のダイブで約4〜5割。旧 約9割）。依頼の「残り◯秒」は円の中にいるときだけ表示され、時間も円の中でだけ減る。ウミガメのそばでシャッターボタンをタップすると、ナイフで網を3回切るモーションが入って助けられる。
- **新しいマップの通知は必ず出る（Phase 3）**: 原則「達成は必ず伝える」→ 問題：通知が1枠のトーストで、直後のトーストに上書きされたり、海図で知っていた場所・深海では出なかった → 専用のバナー「新しいマップを発見！」を作り、初めて入ったマップ（海図で知っていた場所・深海も）で必ず出す（セーブの `visited`）。
- **光景の円と写真スポット（Phase 3）**: 光景も依頼と同じ金色の円でマップに出る（ストーリーの光景は最初から、運の光景は気配が知らされてから）。光景の初回の報酬は `pay × 1/3`（2回目以降は1/7×0.2）。島の名所9か所が「写真スポット」（`src/game/spots.ts`）で、マップの水色の円の中から見どころに向けて撮ると、浮上したときに ¥300〜2,000 がもらえる（各スポット最初の1回だけ、セーブの `spots`）。アルバムに撮影済みのスポットが並ぶ。
- **デバッグ用の切り替え**: ボート画面の一番下に「進行度0にする」と「全部解禁済みにする」（どちらも確認あり）。
- **依頼は陸で受ける**（`src/game/quests.ts`）: 「依頼の掲示板」で最大2件まで受け、場所はマップに金色の円（半径22m）で出る。円に入るとやり方の案内が出て始まる（ウニ漁・ごみ拾い・落とし物・宝探し・標識読み取り）。撮影の依頼と生き物調査は、そのエリアで撮るとその場で達成になる。ウミガメが網に絡まっているような出会いは依頼ではなく、その場のハプニングとして起こる。
- **食堂のウニ漁**: 食堂の「今日の仕込み」を押すと、すぐ岩礁へ潜ってウニ漁が始まり、終わると食堂へ戻って結果が出る。その直後に時間ボタンで朝や夜にすると、食堂を閉じてメニューに戻る。
- **しおさい亭の見た目**: 木の壁、のれん、伝票、氷の入ったクーラーなど、海の画面とは違う温かい色にしてある。時間のボタンは1つで、夜は「朝にする（寝る）」、昼は（水中ライトがあれば）「夜にする」。手銛を買うまでは宿として使い、注文・クーラーの欄は出ない。
- **実績**: トップの「実績」ボタンから別画面で見る。
- **生き物の一覧**: `docs/SPECIES.md`（分類ごとの表）。
- **生き物の分散と岩棚**: 同じ場所に群れが重ならないよう、空いている生息地を優先して配置する。ナマコやウニなどの底生生物も数メートルずつ散らばる。岩礁・サンゴ礁・海藻の森には、ダイバーがくぐれる高さ（約1.7〜2m）の岩棚があり、下の暗がりにアカマツカサなど岩陰を好む魚がすむ。
- **ダイブポイントの発見**: 最初は浅瀬ラグーンだけ。潜って泳いだ先のエリアに入ると発見となり、次からボートで直接行ける。見つけにくいブルーホール・水中洞窟・深海は、ショップの海図、ストーリーやしおさい亭の報酬、拾った箱の中身でも分かる。マップにも発見済みの場所だけが書かれる。
- **拾い物**（`src/game/finds.ts`）: ダイブの4割ほどで、海底のどこかに古い木箱・金属ケース・壺が沈んでいる（かすかに光る）。拾って持ち帰ると中身が分かる（硬貨・真珠・海図・ガラクタ）。気絶すると落とす。
- **しおさい亭（陸の食堂）と銛漁**: 手銛はショップで買う装備。買うと港の食堂の女将ハルさんから頼まれごとが来る（最初に海の決まりを教わる）。ロジックは `src/game/fishing.ts`（`FISHING`・`PENALTY`）、画面は `src/game/kitchen.ts`。ショップ・食堂はそれぞれ別画面。
  - 潜水中に銛ボタン（G/Tキー）でカメラと銛を持ち替える。手には実物に近い手銛（アルミのシャフト、三又のパラライザー、ゴムのスリング）や水中銃（チーク材の銃床、2本のゴム、シャフト、リール）が見える。照準に命中率・重さ・獲れない理由が出る。
  - 手銛 → 漁業権＋水中銃 → 大物用水中銃（サメも獲れる）。持ち帰れる重さは5kg → 15kg → 40kg。
  - 獲物を引き寄せるとエアを使い、獲物や拾い物を持って泳ぐほどエアの減りが増え、泳ぎも遅くなる。獲ると血の匂いでサメが寄ってくることがある。
  - ペナルティ: 保護種（ウミガメ・ナポレオンフィッシュ・タツノオトシゴ・クマノミ類など）は獲れるが、ボートで漁協に没収され罰金と評判ダウン。毒のある魚（フグ類・ソウシハギ・ドクウツボ・ヒョウモンダコなど）は、食べると食中毒で病院代、客に出すと慰謝料と評判の大幅ダウン、市場では引き取ってもらえない。図鑑で撮ったことのある種なら、照準とクーラーに「保護種」「毒あり」と出る。
  - 食堂の仕事: 「今日の仕込み：ウニの選別」（1日1回・25秒で食べられるウニだけをタップ）と「ふぐ調理師試験」（評判Lv2から、受験料あり。学科3問＋トラフグの部位の仕分け8問、1問でも間違えると不合格）。免許があればトラフグ・ヒガンフグ・クサフグなどをさばいて出せる（ほかの毒魚は免許があってもだめ）。
  - 海中の依頼にウミガメの救出（ゴーストネットの網を切る）、生き物調査（3種をB以上で撮る）、研究所の標識読み取り（大きな生き物を照準に2秒）を追加。
  - 食堂では注文に合う魚を出してお金と評判を得る。自分で食べる「まかない」は次のダイブに効く。余った魚は市場へ。評判Lv1〜6で食堂の話が進み、漁具や海図が手に入る。
- **昼と夜**: 1日の潜水時間が約10分を超えると日が傾き、約13分で夜の海になる。浮上すると夜になる（食堂のウニ漁の短いダイブは除く）。しおさい亭の時間ボタンで寝ると翌朝、水中ライトがあれば昼から夜にもできる。
- **潜水中の依頼（ミニゲーム）**: 1ダイブに最大2回、潜って40秒以降に時々「依頼が来た！」と提案される（`src/game/missions.ts` の `MISSION`）。内容・制限時間・報酬を見て「受ける」を押したときだけ始まり、「断る」か15秒放置で消える。失敗してもペナルティなし。
  - ウニ漁（岩礁・流氷の入り江・海藻の森）: 150秒で8点。ウニは全27個が数メートルおきに散らばっていて、近づいてシャッターボタン（バール）を3回押してはがす。食べられるのはムラサキウニ（黒紫・トゲ長め、1点）とアカウニ（赤茶色・トゲ少し短め・高級、2点＋ボーナス）。トゲがとても長いガンガゼと、花のような桃色のラッパウニは触るとトゲや毒でエアが減る（`missions.ts` の `URCHINS`）
  - 海のごみ拾い（ラグーン・サンゴ礁）: 80秒でごみ6個
  - 雑誌の撮影依頼（全域）: 近くにいる生き物を90秒以内にB評価以上で撮る
  - 落とし物のカメラ探し（サンゴ礁・ドロップオフ）: マップの金色の円と「近い／遠い」のヒントで探す
  - **依頼の範囲はマップに円で出る**（点ではない）。落とし物・宝箱・ウミガメは半径18mの円で、円の中心からずらした「円の中のどこか」にある（`MISSION.area`）。ウニ漁とごみ拾いは散らばっている範囲全体を囲む円。大きいマップにも同じ円が出る
  - 依頼のパネル（タイトル・残り時間・進み具合）は画面の上端（縦画面ではミニマップの右）に出る。照準のまわりをふさがない。表示中はお知らせが一段下に出る。残り時間は先頭に書くので、幅が狭くても切れない
- **海の哺乳類・ペンギン・伝説の古生物**: シャチ・マッコウクジラ（沖・深海）、トド・ゴマフアザラシ・キタオットセイ・ラッコ（流氷の入り江、好奇心が強く寄ってくる種も）、コウテイペンギン・イワトビペンギン（本来は南半球の鳥だが入り江に出る）。レア度★4「伝説」の古生物（出現率7%）: シーラカンス、ダンクルオステウス・メガロドン（突進してくる個体あり）、フタバスズキリュウ、アンモナイト、アノマロカリス、三葉虫。流氷の入り江の魚・カニ・エビも追加。さらにスズメダイ・ハゼ・ウミウシ・甲殻類・頭足類・イルカなど148種を加えて全600種。
- **新マップ（西側・東側）**:
  - 海底遺跡・沈船の墓場: 正方形5段のピラミッド（大階段と頂上の神殿、神殿の中に宝箱）、柱や門、崩れた石塊、3隻の沈没船（沈没船の中にも宝箱）。宝探しの依頼が出る
  - ブルーホール: 東の沖の海山の台地に開いた深さ55mの縦穴（西の遺跡・洞窟と固まらないよう Phase 5 で移動）。壁の28〜44mに鍾乳石。オウムガイ、オオメジロザメなど
  - 水中洞窟（セノーテ）: 縦穴から天井付きの通路へ。天井の下は日光が届かず暗い（ライトがないと撮れない）。黄色いガイドロープ、奥の大広間にムカデエビ
  - 海藻の森（東側）: 水面まで伸びるジャイアントケルプの森（カリフォルニア沖がモデル）。ガリバルディ、シープヘッド、タツノオトシゴ、カリフォルニアアシカなど。ウニ駆除の依頼も出る
- **ナイトダイブ**: タイトルで切り替え。全ポイントで夜に潜れる。暗く、ライトで照らさないと撮れない。泳ぐと夜光虫が光る。夜だけ出る生き物（ウミホタル、ゾウリエビ、ハナイカ、寝袋で眠るブダイ、ゴシキエビ、ウチワエビ、ヒメイカなど計14種）と夜間手当×1.3。リスク: 水中ライトが必要、昼の魚は4割に減る、オキザヨリがライトに突進。夜だけの特別な光景: ライトに集まるマンタ／ハダカイワシの日周鉛直移動／ヒカリキンメダイの群れの明滅。

- **海図と探索（Phase 5）**: マップは航空写真風で、自然の地形だけが分かる（深い所ほど青が濃く、浅い所は海底の色が透ける）。海底遺跡・洞窟の通路・沈没船は描かれない。未発見のダイブポイントは「×？」とだけ出て、残りの数も分からない。マップの外側も海（南は浜と陸）が続き、端まで泳ぐと潮の流れに押し戻されて「これ以上は進めない」と出る。
- **宝箱（Phase 5）**: 各マップに1つ（全10個）。近づくと金色に光り、そばでシャッターを押すと開く。沈没船・遺跡の神殿・水中洞窟の奥には限定装備（年代物のレギュレーター＝エアの減り −10%、古代の黄金のフィン＝泳ぐ速さ +10%、探検家のコンパス＝ミニマップの縁にボートの方向の矢印）。他の箱は、まだ撮っていない特別な光景の「古い手記の切れはし」（アルバムに光景の名前と手記が出る）。光景を全部撮ったあとの箱は銀貨 ¥1,000。開けた箱はセーブされ、ショップの「宝箱で見つけた装備」に限定装備が並ぶ。
- **マリンスノー（Phase 5）**: 白い粒子は深海（水深120mから出始め、170mで最大）だけに出る。浅い沖やブルーホールでは出ない（夜光虫の青い光は別）。
