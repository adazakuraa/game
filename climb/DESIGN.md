# 8000m — 単独登頂 (Design Brief)

参考スキル: majidmanzarpour/threejs-game-skills (threejs-game-director / gameplay-systems /
aaa-graphics-builder / game-ui-designer / qa-release)。アセットはすべて手続き生成（外部API・課金なし）。

## Design brief
- **Player promise**: デスゾーンを一人で、薄い空気・寒さ・風と戦いながらエベレスト/K2の頂を目指し、生きて帰る。
- **Target feeling**: 息苦しさ・一歩の重さ・滑落の恐怖・夜明けと山頂の解放感。
- **Primary verb**: 登る（一歩ずつ前進）。
- **Secondary verbs**: 休む（呼吸を整える）、フィックスロープへのクリップ/付け替え、酸素流量の調整、
  ピッケルで滑落停止、ボンベ交換。
- **5〜30秒の反復**: 数歩進む → 息が上がる → 休む / 酸素流量を調整 → アンカーでカラビナ付け替え。
- **1〜5分の変化**: 標高・時刻（夜→夜明け→昼）・風・地形（雪稜→岩場→急峻なステップ）が変わる。
- **失敗**: 滑落、低体温症、高所脳浮腫(HACE)、凍死（行動不能）。死因と標高・時刻を表示、即リトライ。
- **報酬/リスク**: 酸素を多く使えば楽だが帰りの分がなくなる。ロープに付け替えれば安全だが時間を使う。
- **上手いプレイヤー**: 休むタイミングと流量を管理し、急斜面では必ずクリップ、ターンアラウンド時刻を守る。
- **Non-goals**: 仲間/マルチ、ベースキャンプからの高度順応行程、写真のような実在地形データ。

## Core loop contract
Player **一歩ずつ登る** to reach **山頂、そしてC4へ帰還** while **低酸素・寒さ・風・急斜面** create risk;
success gives **標高と次のランドマーク（夜明け・山頂）**, failure causes **死因つきのリトライ**.

## Level plan
- エベレスト南東稜: C4サウスコル(7,950m) → バルコニー(8,400m) → 南峰(8,750m) → ヒラリーステップ → 山頂(8,849m)
- K2 アブルッツィ稜: C4ショルダー(7,600m) → ボトルネック(8,200m, セラック崩落) → トラバース → 山頂(8,611m)
- 時間圧縮: ゲーム内1秒 = 30秒。午前3時出発、夜明け約5:30、ターンアラウンド14:00。
- 垂直方向は実標高差を圧縮（表示標高 = 基準 + 高低差×係数）。
- 急斜面区間にはフィックスロープとアンカー。セクションごとに難度上昇。

### 第3弾：コジオスコ・チュートリアル（2026-11）
オーストラリア最高峰コジオスコ（2,228m）の冬、ローソン峠から山頂までを実際に登りながら操作を覚える練習ステージ（約5分、水平 約330m）。旧「画面の見かた」コーチマーク（ゲームを止めて HUD を指す）は廃止した。実装は `src/game/Coach.ts`。

| --- | --- | --- |
| #017/#233 最初の3分で面白さ | 説明画面から始まり、山に着くまでが長い | 山頂が見える峠から即スタート。最初の操作は「8m 歩く」だけ |

| #113 説明はプレイ中に | 説明のたびにゲームが止まる | 小さなレッスンカード（n / 12 と進捗バー）とガイドの無線だけ。モーダルなし |

遠征セーブ・遺品・犬・所持金・日数には一切触れない（記録は `kosciuszko:up` のキーだけ）。地形は `soft` ステージ：丸い高原にし、遠方は軸に沿った滑らかな稜線に溶かして、ガリーが壁として横に伸びないようにした。

### 3Dモデルの作り方（犬・キャンプの食事）
参考: [img2threejs](https://github.com/anbeime/skill/tree/main/skills/img2threejs)（コードだけで手続き的に3Dモデルを作るスキル）の考え方。
有料の生成API（Tripo / Meshy）や Blender は使わず、すべてコードで作っている。
- **面の種類で作り方を決める**：生き物のなめらかな形（胴・首・頭・脚・尾）は箱や球を積まず、断面を背骨の曲線に沿って掃引（sweep）した一続きの面にする。器（カップ・皿・マグ・ボンベ）は断面を回転（lathe）させ、壁の厚みと巻いた縁をつける。麺・尾・箸は太さが変わる管（strand）。耳は薄い殻を湾曲させる。
- **パスごとに作って確かめる**：形 → 構造（関節・継ぎ目）→ 質感 → 照明、の順に作り、毎回スクリーンショット（横・斜め前・後ろ・歩行中）で確認した。脚の付け根の継ぎ目、鹿のように見える細長い脚、鏡文字になったカップの印刷、内向きの面などは、確認の中で見つけて直した。
- **質感は色と凹凸を別々に**：犬の毛色は頂点ごとに塗り分け（黄褐色の地、濃い背、クリーム色の胸・腹・口元・足先）、毛並みの筋は別のテクスチャと凹凸マップで表す。汁や紅茶は艶のある面、ステンレスと箔は金属、ホーローはクリアコート。
