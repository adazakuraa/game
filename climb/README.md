# DEATH ZONE 8000

ブラウザで動く一人称の高所登山サバイバル（Three.js / TypeScript / Vite）。エベレスト南東稜と K2 アブルッツィ稜を、C4 から単独でサミットプッシュし、生きて帰ることが目標。
スマホ（タッチ）と PC（キーボード＋マウス）の両方に対応。アセットはすべて手続き生成で、外部 API や有料素材は使っていない。

## 遊び方

| 操作 | スマホ | PC |
| --- | --- | --- |
| 移動 | 画面左側をドラッグ | WASD |
| 視点 | 画面右側をドラッグ | マウス（クリックでポインタロック） |
| 休む / 滑落停止（ピッケル） | 「休む」長押し | Space 長押し |
| フィックスロープへのクリップ / アンカーで付け替え / 外す | 「クリップ」 | E |
| ボンベ回収・交換 | 「回収」「交換」 | F |
| 酸素流量 −/＋ | HUD の −/＋ | Z / X |
| 一時停止 | 右上ボタン | Esc |

### 再現している要素
- **酸素と SpO₂**: 標高と酸素流量（0〜4 L/分）から血中酸素濃度を計算。流量を上げると楽になるが、ボンベの減りが早い。ボンベ交換中は手袋を外すので凍傷が進む。
- **体力・呼吸・心拍**: 登るほど息が上がり、休むと回復する。低酸素では回復が遅い。心音は状態に連動。
- **体温・凍傷**: 気温、風速（風冷え）、運動による発熱から体温を計算。立ち止まると冷える。
- **HACE（高所脳浮腫）**: SpO₂ が低い状態が続くと進行し、視界が揺れ、最後には死亡する。
- **フィックスロープ**: 急斜面にはロープとアンカーがある。確保していればスリップしても止まる。アンカーではカラビナの付け替えが必要。急斜面を無確保で歩くと滑落する危険がある。
- **滑落と滑落停止**: 滑ったらピッケルを打ち込んで止める。斜面が急すぎたり、速度が出すぎると助からない。
- **天候**: 予告付きの突風（身を低くして耐える）、午後に崩れる天気、嵐によるホワイトアウト。
- **時間**: ゲーム内時間は現実の20倍速。キャンプ間の移動は早朝に出発し日没（18:30）までに着く。山頂アタックは前夜23時にC4を出発し、ヘッドランプで夜通し登って5時半ごろに夜明け。折り返し時刻は14時。
- **K2 のセラック崩落**: トラバース中に崩落音が聞こえたら、落下ラインから離れる。

## 開発

```bash
npm install
npm run dev        # http://127.0.0.1:5188
npm run build      # dist/
node scripts/make-artifact.mjs dist dist/artifact.html   # 単一ファイル版
```

テスト用フック `window.__THREE_GAME_TEST_HOOKS__.setState(name)` で各シーンに直接移動できる（`title`, `night-start`, `active-play`, `ridge`, `k2-bottleneck`, `storm`, `fail`, `summit`）。

制作フローは [majidmanzarpour/threejs-game-skills](https://github.com/majidmanzarpour/threejs-game-skills) の SKILL.md（director / gameplay-systems / aaa-graphics-builder / game-ui-designer / qa-release）を参考にした。設計メモは `DESIGN.md` にある。
